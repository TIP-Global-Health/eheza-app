# OpenMRS Phase 2 — Prenatal Encounter Transfer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transfer a complete E-Heza prenatal encounter (all ~30 measurement types, 100+ fields) into OpenMRS as one Encounter with one observation per field, using self-provisioned concepts and no OCL/UVL dictionary dependency.

**Architecture:** A checked-in concept catalog (one row per E-Heza prenatal field, generated by Drupal introspection) is the single source of truth. `provision.py` creates one OpenMRS Concept per catalog row and records the UUIDs in config. The Drupal `hedley_openmrs` module queues a prenatal encounter on save, POSTs a flat payload (encounter + all measurement field values) to OpenFN, and exposes an `encounter-link` write-back endpoint. Three OpenFN jobs (transform/match/load) loop the catalog to build the OpenMRS encounter and write its UUID back to E-Heza. Mirrors the Phase 1 patient flow exactly.

**Tech Stack:** Drupal 7 (PHP, drush, advanced_queue), Python 3 (provision.py, stdlib only), OpenFN jobs (JavaScript, `@openfn/language-common` / `@openfn/language-http`, tested with `node --test`).

**Spec:** `docs/superpowers/specs/2026-06-01-openmrs-prenatal-encounter-design.md`

**Datatype mapping** (used by the generator and asserted in tests):

| Drupal field type | OpenMRS Concept datatype |
|---|---|
| `number_integer`, `number_float`, `number_decimal` | `Numeric` |
| `datetime`, `date`, `datestamp` | `Date` |
| `list_boolean` | `Boolean` |
| everything else (`list_text`, `text`, `text_long`) | `Text` |

**JSON-key convention:** the payload key is the field machine name with the `field_` prefix stripped (e.g. `field_hemoglobin_count` → `hemoglobin_count`), matching the restful endpoints.

**Skip set** (operational/reference fields never mapped to obs): `field_prenatal_encounter`, `field_uuid`, `field_shard`, `field_nurse`, `field_person`, `field_deleted`, `field_health_center`.

```php
/**

 * Encounter, not an observation.

function _hedley_openmrs_prenatal_bundles() {
  return [
    'appointment_confirmation', 'prenatal_aspirin', 'prenatal_blood_gprs_test',
    'prenatal_breastfeeding', 'prenatal_calcium', 'prenatal_fefol',
    'prenatal_folate', 'prenatal_follow_up', 'prenatal_gu_exam',
    'prenatal_hemoglobin_test', 'prenatal_hepatitis_b_test',
    'prenatal_hiv_pcr_test', 'prenatal_hiv_test', 'prenatal_iron',
    'prenatal_labs_results', 'prenatal_malaria_test', 'prenatal_mebendazole',
    'prenatal_medication_distribution', 'prenatal_mental_health',
    'prenatal_mms', 'prenatal_outside_care', 'prenatal_partner_hiv_test',
    'prenatal_random_blood_sugar_test', 'prenatal_send_to_hc',
    'prenatal_speciality_care', 'prenatal_symptom_review',
    'prenatal_syphilis_test', 'prenatal_tetanus_immunisation',
    'prenatal_ultrasound', 'prenatal_urine_dipstick_test', 'vitals',
  ];
}

/**
 * Fields never mapped to an observation (operational / reference fields).
 */
function _hedley_openmrs_skip_fields() {
  return [
    'field_prenatal_encounter', 'field_uuid', 'field_shard', 'field_nurse',
    'field_person', 'field_deleted', 'field_health_center',
  ];
}

/**
 * Maps a Drupal field type to an OpenMRS concept datatype.
 */
function _hedley_openmrs_concept_datatype($drupal_type) {
  $numeric = ['number_integer', 'number_float', 'number_decimal'];
  $date = ['datetime', 'date', 'datestamp'];
  if (in_array($drupal_type, $numeric, TRUE)) {
    return 'Numeric';
  }
  if (in_array($drupal_type, $date, TRUE)) {
    return 'Date';
  }
  if ($drupal_type === 'list_boolean') {
    return 'Boolean';
  }
  return 'Text';
}

/**
 * Builds a human-readable concept name from a field key.
 *
 * "field_hemoglobin_count" -> "E-Heza Hemoglobin Count".
 */
function _hedley_openmrs_concept_name($field_name) {
  $base = preg_replace('/^field_/', '', $field_name);
  return 'E-Heza ' . ucwords(str_replace('_', ' ', $base));
}

/**
 * Callback: build the prenatal concept catalog and write it to JSON.
 */
function hedley_openmrs_drush_build_prenatal_catalog() {
  $skip = _hedley_openmrs_skip_fields();
  $rows = [];
  $seen = [];

  foreach (_hedley_openmrs_prenatal_bundles() as $bundle) {
    $instances = field_info_instances('node', $bundle);
    foreach ($instances as $field_name => $instance) {
      if (in_array($field_name, $skip, TRUE) || isset($seen[$field_name])) {
        continue;
      }
      $field = field_info_field($field_name);
      if (empty($field)) {
        continue;
      }
      $seen[$field_name] = TRUE;
      $key = preg_replace('/^field_/', '', $field_name);
      $rows[] = [
        'eheza_key' => $key,
        'concept_name' => _hedley_openmrs_concept_name($field_name),
        'datatype' => _hedley_openmrs_concept_datatype($field['type']),
        'measurement' => $bundle,
      ];
    }
  }

  // Stable order so the committed file has a deterministic diff.
  usort($rows, function ($a, $b) {
    return strcmp($a['eheza_key'], $b['eheza_key']);
  });

  $path = DRUPAL_ROOT . '/../../integration/openmrs/prenatal-concept-catalog.json';
  $json = drupal_json_encode($rows);
  // Pretty-print for a readable diff (drupal_json_encode is compact).
  $json = json_encode($rows, JSON_PRETTY_PRINT | JSON_UNESCAPED_SLASHES);
  file_put_contents($path, $json . "\n");

  drush_print(sprintf('Wrote %d catalog rows to %s', count($rows), $path));
}
```

```python
CONCEPT_DATATYPES = {

    'Text': '8d4a4ab4-c2cc-11de-8d13-0010c6dffd0f',

CATALOG = Path(
    os.environ.get(
        'OPENMRS_PRENATAL_CATALOG',
        str(Path(__file__).resolve().parent / 'prenatal-concept-catalog.json'),
    )
)


def ensure_concept(name, datatype):
    """Idempotently create a concept by fully-specified name; return UUID."""
    uuid = find('concept', name)
    if uuid:
        print(f'  = concept "{name}" exists')
        return uuid
    created = api('/concept', 'POST', {
        'names': [{
            'name': name,
            'locale': 'en',
            'conceptNameType': 'FULLY_SPECIFIED',
        }],
        'datatype': CONCEPT_DATATYPES[datatype],
        'conceptClass': CONCEPT_CLASS_MISC,
    })
    print(f'  + concept "{name}" created ({datatype})')
    return created['uuid']


def provision_prenatal_concepts():
    """Create one concept per catalog row; return {eheza_key: uuid}."""
    if not CATALOG.exists():
        print(f'  ! catalog {CATALOG} not found — skipping concepts',
              file=sys.stderr)
        return {}
    rows = json.loads(CATALOG.read_text())
    concepts = {}
    for row in rows:
        concepts[row['eheza_key']] = ensure_concept(
            row['concept_name'], row['datatype']
        )
    print(f'  provisioned {len(concepts)} prenatal concepts')
    return concepts
```

```php
/**
 * Builds the prenatal-encounter payload sent to OpenFN.
 *
 * Gathers the encounter node plus every measurement node that references
 * it, flattening each measurement's field values into a single
 * `measurements` map keyed by the field name minus its `field_` prefix.
 *
 * @param object $node
 *   The prenatal_encounter node.
 *
 * @return array
 *   The payload, or NULL when the person is not yet linked to OpenMRS.
 */
function hedley_openmrs_build_prenatal_payload($node) {
  // The encounter references the individual participant; from it we reach
  // the person and the person's OpenMRS UUID (set by the Phase 1 flow).
  $person_node = _hedley_openmrs_encounter_person($node);
  if (empty($person_node)) {
    return NULL;
  }
  $person_openmrs_uuid =
    _hedley_openmrs_field($person_node, 'field_openmrs_uuid');
  if (empty($person_openmrs_uuid)) {
    // Person not linked yet — caller turns this into a retry.
    return NULL;
  }

  $measurements = [];
  foreach (_hedley_openmrs_encounter_measurements($node->nid) as $m_node) {
    $skip = array_flip(_hedley_openmrs_skip_fields());
    foreach (field_info_instances('node', $m_node->type) as $field_name => $i) {
      if (isset($skip[$field_name])) {
        continue;
      }
      $value = _hedley_openmrs_field($m_node, $field_name);
      if ($value !== NULL && $value !== '') {
        $key = preg_replace('/^field_/', '', $field_name);
        $measurements[$key] = $value;
      }
    }
  }

  return [
    'encounter_uuid' => _hedley_openmrs_field($node, 'field_uuid'),
    'encounter_date' => _hedley_openmrs_field($node, 'field_scheduled_date'),
    'person_uuid' => _hedley_openmrs_field($person_node, 'field_uuid'),
    'person_openmrs_uuid' => $person_openmrs_uuid,
    'existing_encounter_uuid' =>
      _hedley_openmrs_field($node, 'field_openmrs_encounter_uuid'),
    'measurements' => $measurements,
  ];
}

/**
 * Loads the person node for a prenatal encounter via its participant.
 *
 * @param object $node
 *   The prenatal_encounter node.
 *
 * @return object|null
 *   The person node, or NULL.
 */
function _hedley_openmrs_encounter_person($node) {
  $participant_id =
    _hedley_openmrs_field($node, 'field_individual_participant');
  if (empty($participant_id)) {
    return NULL;
  }
  $participant = node_load($participant_id);
  if (empty($participant)) {
    return NULL;
  }
  $person_id = _hedley_openmrs_field($participant, 'field_person');
  return empty($person_id) ? NULL : node_load($person_id);
}

/**
 * Loads all measurement nodes that reference a prenatal encounter.
 *
 * @param int $encounter_id
 *   The prenatal_encounter node id.
 *
 * @return array
 *   Loaded measurement nodes.
 */
function _hedley_openmrs_encounter_measurements($encounter_id) {
  $query = new EntityFieldQuery();
  $query->entityCondition('entity_type', 'node')
    ->fieldCondition('field_prenatal_encounter', 'target_id', $encounter_id)
    ->addMetaData('account', user_load(1));
  $result = $query->execute();
  if (empty($result['node'])) {
    return [];
  }
  return node_load_multiple(array_keys($result['node']));
}

/**
 * The `_hedley_openmrs_skip_fields()` and `_hedley_openmrs_prenatal_bundles()`
 * helpers live in hedley_openmrs.drush.inc; require it so they are available
 * outside drush (e.g. from the queue worker).
 */
module_load_include('inc', 'hedley_openmrs', 'hedley_openmrs.drush');
```

```php
/**
 * Advanced-queue worker: POST a prenatal encounter to the OpenFN webhook.
 *
 * @param object $queue_item
 *   The queue item; its data holds 'encounter_id'.
 *
 * @return array
 *   An advanced-queue status/result array.

function hedley_openmrs_push_prenatal_encounter_worker($queue_item) {
  $encounter_id = !empty($queue_item->data['encounter_id'])
    ? $queue_item->data['encounter_id'] : NULL;
  if (!$encounter_id) {
    return [
      'status' => ADVANCEDQUEUE_STATUS_FAILURE,
      'result' => t('Queue item has no encounter ID.'),
    ];
  }

  $webhook_url = variable_get('hedley_openmrs_openfn_encounter_webhook_url', '');
  if ($webhook_url === '') {
    return [
      'status' => ADVANCEDQUEUE_STATUS_FAILURE_RETRY,
      'result' => t('OpenFN encounter webhook URL is not configured.'),
    ];
  }

  $node = node_load($encounter_id);
  if (empty($node) || $node->type !== 'prenatal_encounter') {
    return [
      'status' => ADVANCEDQUEUE_STATUS_FAILURE,
      'result' => t('Prenatal encounter @id not found.', ['@id' => $encounter_id]),
    ];
  }

  $payload = hedley_openmrs_build_prenatal_payload($node);
  if ($payload === NULL) {
    // Person not linked to OpenMRS yet — wait and retry.
    return [
      'status' => ADVANCEDQUEUE_STATUS_FAILURE_RETRY,
      'result' => t('Encounter @id person not yet linked to OpenMRS.', ['@id' => $encounter_id]),
    ];
  }

  $headers = ['Content-Type' => 'application/json'];
  $token = variable_get('hedley_openmrs_openfn_token', '');
  if ($token !== '') {
    $headers['X-OpenFN-Token'] = $token;
  }

  $response = drupal_http_request($webhook_url, [
    'method' => 'POST',
    'headers' => $headers,
    'data' => drupal_json_encode($payload),
    'timeout' => 30,
  ]);

  $code = isset($response->code) ? (int) $response->code : 0;
  if ($code >= 200 && $code < 300) {
    return [
      'status' => ADVANCEDQUEUE_STATUS_SUCCESS,
      'result' => t('Pushed prenatal encounter @id to OpenFN.', ['@id' => $encounter_id]),
    ];
  }

  $permanent = $code >= 400 && $code < 500 && $code !== 429;
  $status = $permanent
    ? ADVANCEDQUEUE_STATUS_FAILURE
    : ADVANCEDQUEUE_STATUS_FAILURE_RETRY;
  return [
    'status' => $status,
    'result' => t('OpenFN push for encounter @id failed (HTTP @code).', [
      '@id' => $encounter_id,
      '@code' => $code,
    ]),
  ];
}
```

```php
/**
 * Write-back endpoint: store an OpenMRS encounter UUID on a prenatal encounter.
 *
 * Called by the OpenFN load step once it has created the encounter in
 * OpenMRS. Expects a POST with JSON body holding "encounter_uuid" and
 * "openmrs_uuid", authenticated with the shared secret in X-OpenFN-Token.
 *
 * @return array
 *   A JSON-serialisable response array.
 */
function hedley_openmrs_encounter_link() {
  if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
    return _hedley_openmrs_error('405 Method Not Allowed', 'Use POST.');
  }

  $expected = variable_get('hedley_openmrs_shared_secret', '');
  $provided = isset($_SERVER['HTTP_X_OPENFN_TOKEN'])
    ? $_SERVER['HTTP_X_OPENFN_TOKEN'] : '';
  if ($expected === '' || !hash_equals($expected, $provided)) {
    return _hedley_openmrs_error('401 Unauthorized', 'Invalid token.');
  }

  $payload = json_decode(file_get_contents('php://input'), TRUE);
  if (!is_array($payload)) {
    return _hedley_openmrs_error('400 Bad Request', 'Invalid JSON body.');
  }

  $payload += ['encounter_uuid' => '', 'openmrs_uuid' => ''];
  $encounter_uuid = trim($payload['encounter_uuid']);
  $openmrs_uuid = trim($payload['openmrs_uuid']);
  if ($encounter_uuid === '' || $openmrs_uuid === '') {
    return _hedley_openmrs_error('400 Bad Request', 'Missing required fields.');
  }
  $uuid_re = '/^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i';
  if (!preg_match($uuid_re, $encounter_uuid)
      || !preg_match($uuid_re, $openmrs_uuid)) {
    return _hedley_openmrs_error('400 Bad Request', 'Malformed UUID.');
  }

  $query = new EntityFieldQuery();
  $query->entityCondition('entity_type', 'node')
    ->entityCondition('bundle', 'prenatal_encounter')
    ->fieldCondition('field_uuid', 'value', $encounter_uuid)
    ->range(0, 1)
    ->addMetaData('account', user_load(1));
  $result = $query->execute();

  if (empty($result['node'])) {
    return _hedley_openmrs_error('404 Not Found', 'Unknown encounter UUID.');
  }

  $nid = key($result['node']);
  $node = node_load($nid);

  $existing = _hedley_openmrs_field($node, 'field_openmrs_encounter_uuid');
  if (!empty($existing) && $existing !== $openmrs_uuid) {
    watchdog(
      'hedley_openmrs',
      'Refusing to relink encounter @nid: was @old, asked to set @new.',
      ['@nid' => $nid, '@old' => $existing, '@new' => $openmrs_uuid],
      WATCHDOG_WARNING
    );
    return _hedley_openmrs_error(
      '409 Conflict',
      'Encounter already linked to a different OpenMRS encounter.'
    );
  }

  $node->field_openmrs_encounter_uuid[LANGUAGE_NONE][0]['value'] = $openmrs_uuid;
  node_save($node);

  watchdog('hedley_openmrs', 'Linked encounter @nid to OpenMRS encounter @uuid.', [
    '@nid' => $nid,
    '@uuid' => $openmrs_uuid,
  ], WATCHDOG_INFO);

  return [
    'status' => 'ok',
    'nid' => (int) $nid,
    'encounter_uuid' => $encounter_uuid,
    'openmrs_uuid' => $openmrs_uuid,
  ];
}
```

```javascript
/**
 * Transform - E-Heza prenatal-encounter payload -> OpenMRS REST
 * `/encounter` body.
 *
 * Input  (state.data): the encounter payload posted by the E-Heza Drupal
 *        trigger (hedley_openmrs_build_prenatal_payload).

 *        body with one obs per present, catalogued measurement.
 *
 * Adaptor: @openfn/language-common
 */

fn((state) => {
  const data = state.data || {};
  const cfg = state.configuration || {};
  const concepts = cfg.prenatalConcepts || {};
  const measurements = data.measurements || {};

  const present = (v) => v !== null && v !== undefined && v !== '';

  const obs = [];

    const conceptUuid = concepts[key];
    const value = measurements[key];
    // Only emit obs for fields that are in the catalog and have a value.
    if (conceptUuid && present(value)) {
      obs.push({ concept: conceptUuid, value });
    }
  });

  const openmrsEncounter = {

    encounterType: cfg.encounterType,
    location: cfg.location,

    encounterProviders: cfg.provider ? [{ provider: cfg.provider }] : [],
    obs,
  };

  console.log(
    'Transformed E-Heza prenatal encounter',
    data.encounter_uuid,
    '->',
    obs.length,
    'obs'
  );

  return { ...state, openmrsEncounter };
```

```markdown
One E-Heza prenatal encounter becomes one OpenMRS `Encounter` attached to
the already-linked patient, with one `obs` per measurement field. There is
no OCL/UVL dictionary dependency: each field maps to a **self-provisioned**
OpenMRS Concept, listed in `integration/openmrs/prenatal-concept-catalog.json`

2. `transform-encounter.js` loops the catalog → OpenMRS encounter + obs.
3. `match-encounter.js` resolves the patient (create-once).
4. `load-encounter.js` POSTs the encounter and calls `openmrs/encounter-link`.

| Drupal field type | OpenMRS concept datatype | obs value |
|---|---|---|
| number_integer / number_float / number_decimal | Numeric | the number |
| datetime / date | Date | ISO date |
| list_boolean | Boolean | true/false |
| list_text / text / text_long | Text | the string (multi-selects joined) |

## Deferred (PoC scope)

- Re-sync / update of an already-created encounter (void-and-recreate).
- True coded observations with answer concepts (OCL/UVL's call).
- Obs groups / nested structures (flattened to prefixed keys instead).
```
