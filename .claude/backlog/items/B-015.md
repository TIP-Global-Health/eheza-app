### B-015 — /api/file-upload: no extension/size limits — READY · CONFIRMED incl. not-RCE sub-claim (verification sweep 2026-07-06, self-verified)
- Plugin `files_upload__1.1.inc` passes NO validators key (only `'scheme' => 'private'`); contrib `RestfulFilesUpload.php` (restful 7.x-1.10) defaults validators to EMPTY arrays and its fileSaveUpload (:188-207) UNSETS the extension validator entirely when empty ("allow any extension") + no size cap → any extension, any size. Auth required (paired-device access_token; anonymous blocked by default).
- Not-RCE verified two layers: (1) `:219-222` unconditionally renames `.php/.pl/.py/.cgi/.asp/.js` → `.txt`; (2) private:// not web-served — delivery gated by `hedley_restful_file_download_access` (hedley_restful.module:260-288, access_token required). Rename list incomplete (.phtml/.php5/.phar/.svg/.html not covered) but private scheme is the control. Real impact: disk-fill DoS (FILE_EXISTS_RENAME, no dedup) + authenticated malware hosting. Hardening MED.
- Fix: add `'validators' => ['file_validate_extensions' => ['png jpg jpeg'], 'file_validate_size' => [file_upload_max_size()]]` to the options array in files_upload__1.1.inc (matches field_signature/field_photo allowed extensions).
