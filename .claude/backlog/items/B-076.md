### B-076 — ❌ REFUTED 2026-07-22 (traced end-to-end before implementing). ⚠ DO NOT re-pitch — the described symptom is unreachable.

⇒ `String.toInt` cannot fail here; the `Maybe.withDefault noChange` branch is unreachable. Only 3 call sites exist (`View.elm:543/:565/:637`; the hit at `:59` is an import exposing list).

The symptom signs are `Dict sign Int`, where "cleared" has no representation other than removing the key — which toggle already does. A "fix" would add an unreachable branch and invent a state the model can't express.
