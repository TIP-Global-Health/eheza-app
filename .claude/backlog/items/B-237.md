### B-237 — Prenatal HIV: a discordant partnership found from the **partner's** lab result is filed as initial-phase because the phase gate reads the *patient's* HIV test, so the recurrent-phase PrEP prescription is never offered — CONFIRMED (anchors + all four siblings + both consumers verified) · MED · tier 1 · R25 unit 1 — ✅ IMPLEMENTED 2026-09-06 (issue #2205, PR #2206, branch `B-237-discordant-partnership-phase`, base develop @800ef2ef3)
- **Mechanism.** `Pages/Prenatal/Activity/Utils.elm:2776-2781`: `DiagnosisDiscordantPartnershipInitialPhase -> discordantPartnershipDiagnosed && immediateResult .hivTest`, with the recurrent arm gated on `not <| diagnosedAtInitalPhase …`. But `discordantPartnershipDiagnosed` (:2288-2349) is `byPartnerHIVTest || byHIVTest` — two independent sources — while the phase split consults only the patient's own HIV test. Every sibling gates on the test that actually drives it: HIV `.hivTest` (:2762), detectable viral load `.hivPCRTest` (:2769), syphilis `.syphilisTest` (:2783). `PartnerHIVTestValue` carries its own `testPrerequisites` (`Backend/Measurement/Model.elm:1747-1753`), so `labTestWithImmediateResult .partnerHIVTest` exists and is simply unused. `d3bb86fa8` (2024-10-11) added `byPartnerHIVTest` and left the gate untouched — same commit lineage as B-221.
- **Reachability.** Patient's own HIV rapid test run today with `PrerequisiteImmediateResult` and Negative (satisfying `patientHIVNegative`, :2310-2318); partner HIV test deferred to the lab. Nothing fires at the initial phase (no partner result yet). When the partner result lands at the recurrent phase, `immediateResult .hivTest` is still True, so the **Initial** variant matches and suppresses the Recurrent one. Narrow trigger — needs patient-immediate + partner-deferred — so reachability is medium, not high.
- **Impact.** `resolveDiscordantPartnershipSet` (`Pages/Prenatal/Utils.elm:1821-1850`) is called with the Initial variant in the initial-phase medication set (:1951) and the Recurrent variant in the recurrent one (:1966). With the diagnosis parked on Initial after the initial phase has closed, the recurrent Next Steps offers no TDF3TC (PrEP) and the initial phase is over — the prescription is silently skipped. The diagnosis is still recorded and shows on the report, so this is a treatment-offer gap, not data loss. All sites.
- **Not verified.** Whether partner HIV tests are ever actually deferred to the lab in practice rather than run point-of-care — that is what sizes this item, and it is a question for the field, not the code.
