- **Mechanism.** Both phases share one `ncd_referral` record and, for a woman who is not pregnant with hypertension, the same facility:
  ```elm
  -- client/src/elm/Pages/NCD/Utils.elm (after #2555)
  referralTaskCompleted phase assembled =
      getMeasurementValueFunc assembled.measurements.referral
          |> Maybe.map
              (\value ->
                  Backend.Measurement.Utils.referralToFacilityCompleted value.referralSigns value.nonReferralReasons (referralFacility phase assembled)
              )
          |> Maybe.withDefault False
  ```
  A hospital Yes, or No with a reason, saved in the initial phase (stage 3 hypertension) satisfies the lab-results Referral task raised by diabetes or renal complications found later.
- **Impact.** The lab-results Next Steps reads complete; the new referral reason is never put to the nurse. Small population (stage 3 hypertension, or another initial hospital referral, plus a lab-found referral reason in one encounter).
- **Fix shape (guess).** Per-phase answers in the record (a new FIELD is one-release safe; a new enum VALUE is not — see the enum memory), or completion keyed on the diagnoses the answer was saved against. Build with B-582.
