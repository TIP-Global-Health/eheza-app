### B-385 — Kinyarwanda header for the End-Of-Period resilience category reads "end of the FIRST month" above all seven of those messages — READY · CONFIRMED as code; the Kinyarwanda reading needs the author's confirmation · LOW · tier 4 · R33 unit 5 · ihangane only, usage-capped
- **Mechanism.**
  ```elm
  -- client/src/elm/Translate.elm:21314-21319
                  ResilienceCategoryEndOfPeriod ->
                      { english = "End Of Month"
                      , kinyarwanda = Just "Gusoza ukwezi kwa mbere"
                      , kirundi = Nothing
                      , somali = Nothing
                      }
  ```
  This is the `category-header` rendered above every end-of-period message (`viewResilienceMessage` → `Translate.ResilienceCategory message.category`), and the category carries seven messages — end of month 1 through 7. "kwa mbere" reads as "of the first", so the header would say "end of the first month" above the end-of-sixth-month message. The English is generic and correct; only the Kinyarwanda is specific.
- **Why it qualifies.** Objectively-wrong text (a number that contradicts the record it labels), not translation quality — the declined class is wording opinions, which this is not. But the Kinyarwanda reading is the scout's and the orchestrator cannot certify it; **ask the author before acting**. If the reading is wrong, close this as refuted rather than rewriting the string.
- **Impact.** Cosmetic, one header, on a programme that ended Apr/Aug 2025 for all 20 enrolled nurses (see B-383's usage cap).
- **Fix shape (guess).** Drop "kwa mbere" so the Kinyarwanda is as generic as the English.
