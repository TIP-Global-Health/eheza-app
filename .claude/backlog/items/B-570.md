### B-570 — Dashboard "Number of Cephaly": a later in-range head circumference does not end an earlier macrocephaly or microcephaly count unless that visit also holds an ECD warning — READY · LOW · tier 4 · CONFIRMED (code, raised in review round 2 of PR #2498) · DEPLOYED
- **Found 2026-11-09** while building B-481. The progress report now treats a reading with no warning as resolving the earlier one; the dashboard card does not, so the two can disagree for the same child.
- **Mechanism.** An in-range reading stores no head circumference warning, so `numberOfCephaly` (`Pages/Dashboard/View.elm`) maps an encounter with no warnings to Nothing, and the child keeps counting unless the encounter also holds an ECD warning.
- **Fix shape (guess).** The dashboard's encounter data has no measurements; either bring in the reading, or add an explicit in-range warning value (a new enum value needs a two-release rollout, see [[enum-variant-breaks-deployed-clients]]).
