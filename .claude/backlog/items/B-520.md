### B-520 — Prenatal initial phase: "second phase required" compares the sizes of the labs entry's performed and completed tests, so a completed test no longer performed hides a pending one and the encounter offers "End" instead of "Pause" — READY · CONFIRMED (code read) · LOW · tier 4 · side finding of B-519 (PR #2446)
- **Found 2026-10-29** while building B-519, which replaces the same size comparison in NCD.
- **Mechanism.**
  ```elm
  -- client/src/elm/Pages/Prenatal/Encounter/Utils.elm:1044-1053 (develop)
  secondPhaseRequired : AssembledData -> Bool
  secondPhaseRequired assembled =
      (not <| emergencyReferalRequired assembled)
          && (getMeasurementValueFunc assembled.measurements.labsResults
                  |> Maybe.map
                      (\value ->
                          EverySet.size value.completedTests < EverySet.size value.performedTests
                      )
                  |> Maybe.withDefault False
             )
  ```
  An entry with `{TestHIV}` performed and pending and `{TestHemoglobin}` completed but no longer performed has equal sizes, so no second phase is required.
- **Impact.** Unmeasured; needs that stored shape. `labsResultsTestAddedMsgs` removes a test from both sets when it is marked not performed, so the shape comes from older entries or stale copies.
- **Fix shape (guess).** `not (allLabsCompleted value.performedTests value.completedTests)`, with `allLabsCompleted` from `Pages.GlobalCaseManagement.Utils` (lands with #2442/#2446).
