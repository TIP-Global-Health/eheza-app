### B-205 — Prenatal: the nurse flow reopens an encounter left unfinished on an earlier day; the CHW flow does not — READY · CONFIRMED (both branches read verbatim 2026-08-23, B-194 side-finding) · tier 4 · needs a workflow answer
- `Pages/Prenatal/Participant/View.elm` `viewActionsForNurse` decides whether an encounter can be resumed on `isJust encounter.endDate` alone: `activeEncounterId = if isJust encounter.endDate then Nothing else Just encounterId`. Any encounter that was never ended is offered as today's visit, whatever day it was started on.
- `viewActionsForChw` in the same file gates the same decision on `isJust encounter.endDate || encounter.startDate /= currentDate` — a CHW encounter is resumable only on the day it was started, and an older open one is ignored.
- Consequence for the nurse flow: a visit is recorded inside an encounter carrying an earlier scheduled date, so the encounter date, the gestational age computed from it and the visit's position in the timeline all belong to the earlier day. B-194 removed the years-old case (an undated pregnancy now expires), but an encounter left open earlier within a still-active pregnancy is still reopened.
- ⚠ **Not a straight port of the CHW rule.** Same-day-only would stop a nurse finishing an encounter she began yesterday and would leave that encounter open for good — the un-ended-encounter class. Which of the two behaviours is wanted is a workflow question for the team, not a defect with one right answer.
