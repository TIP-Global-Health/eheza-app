### B-364 — Prenatal diagnosis: a lab result entered for an older encounter re-scores it with LATER encounters as history — it can add hyperemesis / pelvic-pain-continued / malaria-medicated-continued (a hospital referral) that the encounter never had, or drop diabetes / moderate preeclampsia that the later encounter already carries — the Prenatal twin of B-339 — READY · CONFIRMED (history builder, the three adding readers and the write-back read by the orchestrator; scout scratch elm-test for six cases) · MED-LOW · tier 1 (diagnosis rule) · R31 unit 5 · DEPLOYED, all sites; LATENT so far — ihangane: 368 prenatal lab-test records last changed after a later nurse encounter existed (upper bound), 0 stored diagnoses of the affected kinds without their own grounds
- **Mechanism.** The history keeps every other encounter of the pregnancy, including later ones:
  ```elm
  -- client/src/elm/Pages/Prenatal/Encounter/Utils.elm:291-298
  generatePreviousMeasurements currentEncounterId participantId db =
      getPrenatalEncountersForParticipantDesc db participantId
          |> List.filter
              (\( id, _ ) ->
                  -- We do not want to get data of current encounter.
                  id /= currentEncounterId
              )
          |> List.sortWith sortEncounterTuples
  ```
  and the scorer reads it as "previous":
  ```elm
  -- client/src/elm/Pages/Prenatal/Utils.elm:4653-4661
  symptomRecordedPreviously assembled symptom =
      assembled.nursePreviousEncountersData
          |> List.filter (\data -> symptomRecorded data.measurements symptom)
          |> List.isEmpty
          |> not
  -- client/src/elm/Pages/Prenatal/Activity/Utils.elm:1201-1206 (hospitalizeDueToNauseaAndVomiting)
          byPreviousEncounters =
              symptomRecorded assembled.measurements NauseaAndVomiting
                  && symptomRecordedPreviously assembled NauseaAndVomiting
  -- :2399-2402
          malariaMedicatedContinuedDiagnosed =
              malariaConditionsMatch
                  && (isJust <| latestMedicationTreatmentForMalaria assembled)
                  && diagnosedPreviouslyAnyOf [ DiagnosisMalariaInitialPhase, DiagnosisMalariaRecurrentPhase ] assembled
  ```
  (`latestMedicationTreatmentForMalaria` → `getLatestTreatmentByTreatmentOptions`, `Pages/Prenatal/Utils.elm:1428`, `List.reverse nursePreviousEncountersData` — the later encounter first). The `not diagnosedPreviouslyAnyOf` guards (diabetes `Activity/Utils.elm:2885-2908`, moderate preeclampsia, preeclampsia risk) hide diagnoses A should keep. The nurse assessment writes the regenerated set back (`Backend/Update.elm:8857-8863` `generatePrenatalDiagnosesForNurse currentDate assembledAfter` → `SetPrenatalDiagnoses`).
- **Reachability.** Encounter A sends a test to the lab → Case Management keeps A's labs entry open 35 days with no later-encounter check (`Pages/GlobalCaseManagement/View.elm:1279-1306`) → a later nurse encounter B starts → the result is entered on `PrenatalRecurrentActivityPage A` (nurse or lab tech) → any of the ten lab revisions → `processRevisionAndAssessPrenatal A` (`Backend/Update.elm:3094-3320`) → the recurrent branch (`:9013`) sends `SetPrenatalDiagnoses` to A. Results entered via B's labs-history page fall to `_ -> []` and are unaffected.
- **Evidence (scout, run).** `generatePrenatalDiagnosesForNurse` on A (EGA 14 w): NauseaAndVomiting alone → `[]`, with later B also NauseaAndVomiting → `[DiagnosisHyperemesisGravidumBySymptoms]`; PelvicPain → `[]` vs `[DiagnosisPelvicPainContinued]`; smear ++ → `[DiagnosisMalariaRecurrentPhase]` vs, with later B `DiagnosisMalariaInitialPhase` + Coartem, `[DiagnosisMalariaMedicatedContinuedRecurrentPhase]`.
- **Impact.** `DiagnosisMalariaMedicatedContinuedRecurrentPhase` is on the recurrent hospital-referral list (`Pages/Prenatal/Utils.elm:302`) → A's recurrent Next Steps demands a hospital referral for malaria B already treated; hyperemesis / severe vomiting / pelvic-pain-continued are initial-phase referral diagnoses (`:262-267`) and appear on A's report and in reports; A loses diabetes or moderate preeclampsia when B has it.
