- **Mechanism.** The history keeps every other encounter of the pregnancy, including later ones:
  ```elm
  -- client/src/elm/Pages/Prenatal/Encounter/Utils.elm:291-298
  generatePreviousMeasurements currentEncounterId participantId db =
      getPrenatalEncountersForParticipantDesc db participantId
          |> List.filter
              (\( id, _ ) ->
                  -- We do not want to get data of current encounter.
                  id /= currentEncounterId
              )
          |> List.sortWith sortEncounterTuples
  ```
  and the scorer reads it as "previous":
  ```elm
  -- client/src/elm/Pages/Prenatal/Utils.elm:4653-4661
  symptomRecordedPreviously assembled symptom =
      assembled.nursePreviousEncountersData
          |> List.filter (\data -> symptomRecorded data.measurements symptom)
          |> List.isEmpty
          |> not
  -- client/src/elm/Pages/Prenatal/Activity/Utils.elm:1201-1206 (hospitalizeDueToNauseaAndVomiting)
          byPreviousEncounters =
              symptomRecorded assembled.measurements NauseaAndVomiting
                  && symptomRecordedPreviously assembled NauseaAndVomiting
  -- :2399-2402
          malariaMedicatedContinuedDiagnosed =
              malariaConditionsMatch
                  && (isJust <| latestMedicationTreatmentForMalaria assembled)
                  && diagnosedPreviouslyAnyOf [ DiagnosisMalariaInitialPhase, DiagnosisMalariaRecurrentPhase ] assembled
  ```
  (`latestMedicationTreatmentForMalaria` → `getLatestTreatmentByTreatmentOptions`, `Pages/Prenatal/Utils.elm:1428`, `List.reverse nursePreviousEncountersData` — the later encounter first). The `not diagnosedPreviouslyAnyOf` guards (diabetes `Activity/Utils.elm:2885-2908`, moderate preeclampsia, preeclampsia risk) hide diagnoses A should keep. The nurse assessment writes the regenerated set back (`Backend/Update.elm:8857-8863` `generatePrenatalDiagnosesForNurse currentDate assembledAfter` → `SetPrenatalDiagnoses`).
