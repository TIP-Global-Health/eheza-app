### B-356 — Lab results pane (Prenatal + NCD progress report): a urine dipstick or lipid panel still waiting for results shows a red "Abnormal" on its summary row, while the rows under it correctly say "Results Pending" — READY · CONFIRMED (all three verdict functions read by the orchestrator; scout scratch render; deployed since 2022-06-20, `8cafd0e09`) · MED-LOW · tier 3 · R31 unit 6 · DEPLOYED, all sites; ihangane live records performed-with-no-result: prenatal dipstick 1,754 (vs 21,296 with results), NCD dipstick 139, NCD lipid panel 21
- **Mechanism.** The summary verdict treats a missing leading result as normal, then combines the other results with a `withDefault False` that assumes the leading result existed:
  ```elm
  -- client/src/elm/Pages/Report/View.elm:737-760 (dipstickShortEntry)
                                              proteinResultNormal_ =
                                                  Maybe.map proteinResultNormal proteinResult
                                                      |> -- It's ok not to have a result, because test
                                                         -- may have been not performed yet.
                                                         Maybe.withDefault True
                                              resultsNormal =
                                                  if not proteinResultNormal_ then
                                                      False
                                                  else
                                                      Maybe.map2
                                                          ...
                                                          (List.head phResults |> Maybe.andThen Tuple.second)
                                                          (List.head glucoseResults |> Maybe.andThen Tuple.second)
                                                          |> -- We should never get here since protein result
                                                             -- existed, and all 3 are entered together.
                                                             Maybe.withDefault False
                                              result =
                                                  if resultsNormal then
                                                      translate language Translate.Normal
                                                  else
                                                      translate language Translate.Abnormal
  ```
  Same shape in `dipstickLongEntry` (`Maybe.map5` `:798` / `Maybe.map3` `:816`, `withDefault False` `:813`, `:827`) and `lipidPanelEntry` (`:887`, `Maybe.map3` `:903`, `withDefault False` `:914`). The drill-down rows render the same empty values through `viewUncompetedResult` ("Results Pending" / "Results Missing").
- **Reachability.** A performed test with an `executionDate` and no results is the normal state between ordering and entering results: `toUrineDipstickTestValue` (`Measurement/Utils.elm:2771-2790`) writes all results `Nothing` for a non-immediate test; NCD lipid panels start that way via `toLipidPanelTestValueWithEmptyResults` (`Pages/NCD/Activity/Update.elm:1679`). `generateLabsResultsPaneData` feeds the pane in the Prenatal (`ProgressReport/View.elm:2058`) and NCD (`:846`) reports, the lab-tech / results-reviewer confirmation view, and the WhatsApp export.
- **Impact.** A test never read shows as Abnormal (warning class) for as long as its results are missing — possibly forever. Scout scratch render: pending short dipstick → `entry warning … Abnormal`; pending lipid panel → `Abnormal`; pending long dipstick → two `Abnormal` rows (one is B-251's phantom Short row). Not measured: how many patients have such a test as their LATEST.
- **Backlog de-dup.** B-251 (dipstick short/long variant mixing) sits in the same functions — fix together. Not recorded.
- **Fix shape (guess).** When the leading result is empty, render the pending/missing state (`viewUncompetedResult`) without a verdict or warning.
