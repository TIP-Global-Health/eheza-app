### B-289 — NCD: a pregnancy found by test at the first encounter is forgotten at every later encounter — the full antihypertensive list (ACE inhibitors) is offered, referral goes to hospital instead of ANC, health education is shown — READY · CONFIRMED mechanism, PLAUSIBLE intent (read the issue behind `35eb194aa` before building) · MED · tier 1 · R26 unit 5
- **Mechanism.** `patientIsPregnant measurements` (`Pages/NCD/Utils.elm:955-963`) reads only the CURRENT encounter's pregnancy test (`executionNote == TestNoteKnownAsPositive || testResult == Just TestPositive`). The test is offered once: `TaskPregnancyTest -> isPersonAFertileWoman … && initialTestRequired TaskPregnancyTest` (`Activity/Utils.elm:897-899`), and `initialTestRequired` is false as soon as a previous encounter has a performed test with a valid result (`:918-938`, `resolveLabTestDate`; "run today" stores `executionDate = currentDate`). So from the second encounter on `patientIsPregnant` is false for a woman who tested POSITIVE last month. Consumers: `generateRecommendedTreatmentSignsForHypertension` (`:398-406`) falls back to `allRecommendedTreatmentSignsForHypertension` (`:409-419`, includes `TreatmentCaptopril`, `TreatmentLisinopril`); `resolveReferralInputsAndTasks` facility (`:813-820`) → `FacilityHospital`; `referForHypertension` loses the "pregnant" arm (`:946-947`); `expectNextStepsTask TaskHealthEducation` (`Activity/Utils.elm:147-148`) no longer suppressed; `medicateForHypertension` Stage-1 arm (`:606-607`) loses the pregnancy trigger.
- **The asymmetry that shows it is unintended.** "Known as positive" is NOT a performed note (`testPerformedByExecutionNote`, `Measurement/Utils.elm:8591-8593`), so a woman who answers that way is re-asked at every encounter and stays pregnant in the logic; only the woman found pregnant BY THE TEST is forgotten.
- **Reachability.** Fertile woman (12 < age < 50), first NCD encounter with a positive on-the-spot pregnancy test; any hypertension diagnosis at the next encounter. A pregnancy outlasts ~8 monthly follow-ups.
- **Impact.** Contraindicated medication options and the wrong referral facility during a pregnancy, on both sites. Distinct from B-224 (report row visibility); this is the activity side.
- **Gate.** `35eb194aa` ("Implement Labs Frequency for NCD", 2022-12-05) set the once-only rule; its issue may state whether pregnancy was meant to be re-asked. Read it first.
- **Fix shape (guess).** Either re-expect the pregnancy test while a positive result is recent (within ~9 months), or make `patientIsPregnant` consult the latest positive result within that window across `previousEncountersData`.
