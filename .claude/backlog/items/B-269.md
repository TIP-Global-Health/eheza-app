### B-269 — `HedleyRestfulBulkPhotosTest` has never run: it declares the group `Hedley restful` while the test job runs the group `Hedley` — READY · CONFIRMED (verified against a CI log, 2026-08-26) · MED · tier 3 · found while building B-244
- **Mechanism.** `.ddev/commands/web/simpletest` ends with `run-tests.sh … Hedley`, and `run-tests.sh` selects by the exact group name a class reports from `getInfo()`. `HedleyRestfulBulkPhotosTest::getInfo()` returns `'group' => 'Hedley restful'` — the ONLY class in the repo that does not say plain `Hedley`. The runner never selects it, so none of its four methods run.
- **Verified, not inferred.** The `test_simpletest_linux` log for build #28877 (branch `b244-person-edit-wipes-photo`) contains six classes — HedleyUserAccessControlTests, HedleyPatientConsolidation, HedleyReportsDataEndpoint, HedleyStockManagementEndpoints, HedleyAdminIntegrityTests, HedleyStatsCalculation — and no line mentioning BulkPhotos.
- **What is uncovered.** The `/api/bulk-photos` container format: manifest/binary assembly, per-item ok/missing/forbidden/error statuses, cumulative offsets across a mixed batch, and the over-cap `RestfulBadRequestException`. All four have been reported green by never running.
- ⚠ **Same class of defect as [[B-248]]** (three `HedleyStatsCalculation` scenarios that exit early), found the same way: **a green CI job is not evidence a test ran.** B-248 is about scenarios inside a class that runs; this is a whole class the runner never selects.
- 📌 The trap it set: B-244's coverage was first folded into this class precisely because it looked like the right home, and it would have shipped as coverage that never executes. Caught by grepping the CI log for the new assertions.
- **Fix shape (guess).** Change the group to `Hedley` so the runner selects it. ⚠ Weigh the cost first: DrupalWebTestCase reinstalls per test METHOD, so admitting four methods adds four installs to a job already at 27.0 min ([[ci-simpletest-time-budget]]). Folding the four methods into one, or one method plus helpers — the shape the rest of the suite uses — keeps the coverage and adds one install. A CI guard that fails when a class declares a group the job does not run belongs with the G-track.
