### B-652 — Prenatal lab results (nurse): the hospital referral question opens with No already chosen when the exam's Referral answered only another place, so one ticked reason saves a refusal the nurse never gave — READY · MED-LOW · tier 3 (care pathway, same tier as B-582) · CONFIRMED (seen in the QA run of pull request 2594 on develop and on the PR build, one woman each; cause read in code) · DEPLOYED, both sites · side-finding of the QA run of pull request 2594, 2026-11-25
- **What the nurse sees.** The exam's Referral asked only about ultrasound (pregnancy dated "not confident", answered Yes). A later lab result needing a hospital referral (positive Hepatitis B, entered from Case Management › ANC Labs) opens the lab results Referral with "Have you referred the patient to the hospital?" set to No, Why not? empty, counter 1/2.
- **Reproduce.** Nurse first antenatal visit, date the pregnancy not confident; send Hepatitis B to the lab; answer the ultrasound referral Yes in Next Steps. Enter a positive Hepatitis B result from ANC Labs, open Next Steps › Referral. Test women: `E2ETest Qa2594DevC`, `E2ETest Qa2594PrC` (local DB).
- **Mechanism.** The lab results page reads the encounter's `sendToHC` record saved by the exam. `referralFormWithDefault` (`Pages/Prenatal/Utils.elm`) fills each place with `Maybe.map (EverySet.member sign) value.referToFacilitySigns`. The exam saved `{ReferToUltrasound, ReferralFormUltrasound}`, so the hospital reads `Just False`, shown as a chosen No.
- **Why PR #2594 does not cover it.** `referralFormWithDefaultRecurrentPhase` blanks the hospital question only when `hospitalReferralAnsweredAtExam saved` (phase stamp `PhaseInitial`). An exam that never asked the hospital leaves no stamp, so the `else` branch keeps the old pre-fill.
- **Fix shape.** As B-573 did for NCD (PR #2555): fill a place's question only when the record answered that place (`Backend.Measurement.Utils.referralToFacilityCompleted`). Check the other places (mental health, ARV, NCD, ultrasound) for the same pre-fill.
- **Precedent.** Issue #2307 (Acute Illness, pre-answered No on a newly shown question); B-573 (NCD). B-592 is a different defect (a No→Yes change keeps the old reason).
