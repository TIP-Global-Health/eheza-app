### B-236 — Prenatal symptoms: whether vaginal discharge counts as "continued" is decided by the patient's **gonorrhea** history, so recurrent bacterial vaginosis is re-treated instead of referred and a past gonorrhea sends a first BV episode to hospital — READY · CONFIRMED (anchors + all four siblings + both consumers verified) · MED-HIGH · tier 3 · R25 unit 1
- **Mechanism.** `Pages/Prenatal/Activity/Utils.elm:3102-3108`: `DiagnosisTrichomonasOrBacterialVaginosis -> trichomonasOrBacterialVaginosisDiagnosed && (not <| diagnosedPreviously DiagnosisGonorrhea assembled)` and `DiagnosisTrichomonasOrBacterialVaginosisContinued -> trichomonasOrBacterialVaginosisDiagnosed && diagnosedPreviously DiagnosisGonorrhea assembled`. Both arms test the **gonorrhea** history rather than their own diagnosis. Every sibling pair in the same `case` keys on itself: candidiasis (:3086-3092), gonorrhea (:3094-3100), UTI (:3069-3075), heartburn/persistent (:3050-3056). Copy-adapted from the gonorrhea block directly above and the sentinel never changed; `git log -S` gives one commit, `8cc5cb5ec` (2022-05-22), which introduced both arms already wrong.
- **The two arms are mutually exclusive, so exactly one always fires — the wrong one for two populations.** Recurrent BV with no gonorrhea history → the plain diagnosis again, never `…Continued`. First-ever BV in a patient with a past gonorrhea → `…Continued`.
- **Reachability.** Nurse → Prenatal → Symptom Review → "Abnormal vaginal discharge", answering *no* to both the vaginal-itching and partner-urethral-discharge follow-ups (`trichomonasOrBacterialVaginosisDiagnosed`, :3023-3031, verified). `resolveSymptomsDiagnoses` (:3566-3568, verified) offers **both** variants on every non-postpartum nurse encounter; `generatePrenatalDiagnosesForNurse` filters and persists via `SetPrenatalDiagnoses`. `diagnosedPreviously` (`Pages/Prenatal/Utils.elm:81-94`) reads `assembled.nursePreviousEncountersData` diagnoses.
- **Impact — the two variants route to different care.** `DiagnosisTrichomonasOrBacterialVaginosisContinued` is in `diagnosesCausingHospitalReferralByImmediateDiagnoses` (`Pages/Prenatal/Utils.elm:270`) → hospital referral. The plain variant instead drives medication: `trichomonasOrBVSet` (`Pages/Prenatal/Utils.elm:1912-1918`, Metronidazole) plus a NextSteps health-education trigger (`Activity/Utils.elm:474, 512`). So a genuinely persistent BV is re-treated with metronidazole instead of referred, and a woman whose only prior STI was gonorrhea is referred on her first BV episode. All sites, no `EHEZA_SITE` split.
- ⚠ **Distinct from B-230** and unaffected by it: `trichomonas-or-bv-continued` **does** decode (`Backend/PrenatalEncounter/Decoder.elm:295-298`, verified) — it is `gonorrhea-continued` that has no decoder branch. Both arms here key on plain `DiagnosisGonorrhea`, which round-trips fine, so B-230 neither masks nor causes this.
- **Fix shape (guess).** Key both arms on `DiagnosisTrichomonasOrBacterialVaginosis`.
