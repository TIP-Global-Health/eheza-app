### B-210 — Antenatal progress report: an outside-care Syphilis or Moderate Anemia diagnosis never shows the medication that was recorded for it — CONFIRMED (orchestrator-traced form → stored value → report guard) · MED · tier 3 · both sites · R23 unit 1
- **Mechanism.** `Pages/Prenatal/ProgressReport/View.elm:3275` gates the "treated with …" phrase on `List.member diagnosis outsideCareDiagnosesWithPossibleMedication`. That list (`Pages/Prenatal/Utils.elm:3283-3291`) holds `DiagnosisSyphilisInitialPhase` and `DiagnosisModerateAnemiaInitialPhase`. The outside-care form offers only `outsideCareDiagnosesLeftColumn`/`RightColumn` (`Utils.elm:3256-3281`, wired at `Pages/Prenatal/Activity/View.elm:725-726`), which contain the **RecurrentPhase** variants, and its medication step is keyed on exactly those (`Activity/View.elm:711-712`: `syphilisDiagnoses = [ DiagnosisSyphilisRecurrentPhase ]`, `anemiaDiagnoses = [ DiagnosisModerateAnemiaRecurrentPhase ]`). A stored Syphilis/Moderate-Anemia outside-care diagnosis therefore fails the outer guard and falls to the `else if List.member diagnosis outsideCareDiagnoses` branch → `completePhrase Nothing` — the penicillin / iron+folic-acid selection in `value.medications` is never rendered. The `…RecurrentPhase ->` arms inside the `case` (`View.elm:~3316/~3345`) are unreachable. HIV, Malaria and the three hypertension-like diagnoses are unaffected (their form and report lists agree). `outsideCareDiagnosesWithPossibleMedication` has exactly ONE consumer (this guard).
- **Reachability.** Nurse → Prenatal encounter → History → Outside Care → new diagnosis Syphilis (or Moderate Anemia) + "given medicine" + pick medication → Save. Progress Report → Medical Diagnosis pane → `outsideCareDiagnosesEntries` (`View.elm:902-913`) → `viewTreatmentForOutsideCareDiagnosis`. Same for the WhatsApp variant (`ComponentAntenatalMedicalDiagnosis`).
- **Impact.** The report line reads "Syphilis – diagnosed by outside care, added to patient record on DD/MM/YYYY" with no treatment — a treated syphilis reads as untreated on the clinical document. No `EHEZA_SITE` split.
- **Fix shape (first guess):** make the guard list agree with what the form stores (RecurrentPhase for syphilis/anemia), or derive both from one list in `Pages.Prenatal.Utils` so they cannot drift again. Sibling: B-211 (same function, HIV sentinel).
