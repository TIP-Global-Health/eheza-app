### B-398 — The simpletest CI log is capped at its last 400,000 bytes, and `--verbose` puts the per-class summary before the part that survives — so no one can see which test classes ran — READY · CONFIRMED (scout sampled four builds; orchestrator independently hit the same truncation) · LOW · tier 4 · R34 unit 3
- **Mechanism.** The wrapper asks for every assertion to be printed:
  ```bash
  -- .ddev/commands/web/simpletest:24
  php ./www/scripts/run-tests.sh --php "$(which php)" --concurrency 4 --verbose --color --url http://eheza-app.ddev.site:8081 Hedley 2>&1 | tee /tmp/simpletest-result.txt
  ```
  `run-tests.sh` prints the per-class `N passes, M fails` summaries first, then `Test run duration:`, then the verbose dump. CircleCI stores only the **last 400,000 bytes** of a step's output, and `HedleyUserAccessControlTests` alone contributes ~2,400 assertion lines, so the cap always falls inside the dump and the summary is gone.
- **Evidence.** Four sampled `test_simpletest_linux` logs (builds 30884, 30873, 30862, 30848) are each exactly 400,000 characters, each begins mid-sentence, and none contains `Test run duration` or any `N passes` line. The step metadata claims `truncated: False`, which is misleading. ⭐ The orchestrator hit this independently while trying to settle whether `HedleyActivityZscoreUpdate` runs: build 30848's output starts mid-word ("osis malaria-continued is counted…"), so the absence of a class name from the log says nothing about whether it ran.
- **Impact.** Diagnosability only — the green/red guard itself is sound, because the wrapper greps its own `/tmp/simpletest-result.txt`, not the CI log. But a human reading either a green or a red simpletest job cannot see which classes ran or how many assertions passed, which is exactly the evidence [[B-269]] and [[B-248]] turn on.
- ⚠ **It weakened one existing evidence line.** B-269's proof was quoted as "the log names six classes and not BulkPhotos". With the front of the log cut, that is not conclusive on its own — B-269 nonetheless **stands**, on the code: `run-tests.sh:589-598` does an exact `isset($groups[$group_name])` match and the class declares `'group' => 'Hedley restful'`.
- **Fix shape (guess).** Drop `--verbose`, or add `--fail-only`, so the summary is what survives the cap.
