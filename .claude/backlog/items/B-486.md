- **Found R42 unit 4 (union-variant inventory):** `PostpartumMotherDangerSign` / `PostpartumChildDangerSign` have ZERO references in any display file, while 14 of 15 `DangerSign` constructors are read.
- **Mechanism.** The pane decides the chip from `signs` alone:
```elm
-- client/src/elm/Pages/Prenatal/ProgressReport/View.elm:1311-1323 (matchCHWActivityAtEncounter)
        ActionDangerSignsPresent ->
            getMeasurementValueFunc measurements.dangerSigns
                |> Maybe.map
                    (\value ->
                        case EverySet.toList value.signs of
                            [] -> False
                            [ NoDangerSign ] -> False
                            _ -> True
```
  A `ChwPostpartumEncounter` danger-signs form offers only the postpartum lists (`Pages/Prenatal/Activity/View.elm:1295-1316`) and never touches `form.signs`, so the stored value is `signs = {NoDangerSign}` with the answer in `postpartumMother` / `postpartumChild` (`toDangerSignsValue`, `Activity/Utils.elm:4275-4292`). The engine's own presence check branches on the encounter type and was updated; the pane was not:
```elm
-- client/src/elm/Pages/Prenatal/Activity/Utils.elm:1446-1462 (noDangerSigns)
    case assembled.encounter.encounterType of
        ChwPostpartumEncounter ->
            ... getDangerSignsType .postpartumMother |> dangerSignsEmpty NoPostpartumMotherDangerSigns
            ... getDangerSignsType .postpartumChild |> dangerSignsEmpty NoPostpartumChildDangerSigns
        _ ->
            getDangerSignsType .signs |> dangerSignsEmpty NoDangerSign
```
  The pane carries the encounter type in its tuple and discards it: `(\( date, _, measurements ) -> ( date, List.filter (matchCHWActivityAtEncounter measurements) allCHWActions ))` (`View.elm:1262-1266`).
- **Reachability.** CHW → prenatal participant → Postpartum (`Participant/View.elm:480`) → Danger Signs → e.g. mother "Fever" → the referral is driven correctly by `noDangerSigns`. Progress report (in-encounter for the CHW, or from the Patient Record for a nurse; B-361 governs which rows appear) → CHW Activity pane → that visit's row has "Referred to Health Center" but no velvet "Danger Signs Present" chip. This pane is the ONLY place postpartum danger signs could surface in any report.
- **Impact.** Display only; a nurse reading a CHW's postpartum history sees no danger-sign flag on a visit that had one. Both sites.
