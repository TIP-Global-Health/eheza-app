### B-323 — Prenatal: a partner HIV result entered by a LAB TECHNICIAN produces no discordant-partnership diagnosis at all, because the match hand-rolls its own execution-note list and omits `TestNoteRunConfirmedByLabTech` — ✅ IMPLEMENTED · CONFIRMED (run) · MED · tier 1 · split out of B-237's review 2026-09-06
- **Mechanism.** `Pages/Prenatal/Activity/Utils.elm`, `discordantPartnershipByPartnerHIVTest` accepts only three notes:
  ```elm
                                if
                                    (value.executionNote == TestNoteKnownAsPositive)
                                        || (List.member value.executionNote [ TestNoteRunToday, TestNoteRunPreviously ]
                                                && (value.testResult == Just TestPositive)
                                           )
                                then
  ```
  Every other disease diagnosis in the same `case` goes through `testedPositiveAt`, which uses the shared predicate `testPerformedByExecutionNote` (`Measurement/Utils.elm`): `List.member executionNote [ TestNoteRunToday, TestNoteRunPreviously, TestNoteRunConfirmedByLabTech ]`. The discordant-partnership match is the only one with a hand-rolled list, and it is the shared list minus `TestNoteRunConfirmedByLabTech`.
- **Reachability.** `toPartnerHIVResultValue` rewrites the note whenever the lab tech confirms the run: `executionNoteConsideringLabTech = if form.runConfirmedByLabTech == Just True then TestNoteRunConfirmedByLabTech else executionNote`. That confirmation question (`contentAndTasksLaboratoryResultConfirmation`) is rendered only `if isLabTech`, so the note flips exactly when a lab technician enters the result — the ordinary path for a partner test sent to the lab. A nurse entering the same result from the recurrent encounter leaves the note at `TestNoteRunToday`, and the diagnosis fires.
- **Impact.** Neither variant matches, so the encounter carries no Discordant Partnership diagnosis: no TDF3TC/PrEP in either phase, and nothing on the progress report. Silent. ⚠ Strictly worse than B-237, which put the diagnosis in the wrong phase; this drops it entirely.
