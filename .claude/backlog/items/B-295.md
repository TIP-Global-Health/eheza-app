### B-295 — Nutrition (individual, CHW): saving Height/Weight as "unable to take" leaves the previously saved measurement alive and feeding assessments — READY · CONFIRMED-mechanism · LATENT (live: **0 occurrences on ihangane AND vhw**, 2026-09-01) · MED-LOW · tier 4 · R27 unit 3
- **Mechanism.** The not-taken branch of `SaveHeight`/`SaveWeight` (`Pages/Nutrition/Activity/Update.elm:119-165`, `:327-373`) only adds the skip flag to the encounter (`AddSkippedForm SkippedHeight/-Weight`) and navigates; it never touches an existing measurement node, and `Backend/NutritionEncounter/Model.elm:73-97` has no delete/void message for any measurement. The encounter then holds BOTH a live `nutrition_height`/`nutrition_weight` node and the skip flag, and the hydration hides the survivor: `heightFormWithDefault` (`Measurement/Utils.elm:743-767`; weight sibling `:831-855`) returns `{ height = Nothing, measurementNotTaken = Just True }` whenever the flag is set — the form shows "unable to take" with an empty input while the stale value keeps feeding `generateNutritionAssessment` (weight → z-scores), previous-value hints, progress reports and dashboards. Contrast WellChild head circumference, where not-taken is stored ON the measurement (`NoteNotTaken`) and the record stays self-consistent.

Flow: save a value → reopen the completed activity → tick "unable to take" (task counts 1/1, Save enabled; the B-029 range gate passes because the hydrated value is `Nothing`) → not-taken branch runs.
- **Liveness.** The coexistence signature (encounter carrying the skip flag AND a live measurement of that type) counts **zero on `ihangane.live` and `vhw.live`** (2026-09-01) — the retraction flow has never been exercised against a saved value. Latent hardening, not live damage; `activityCompleted` staying `True` via the `isJust measurements.height ||` arm (`Pages/Nutrition/Activity/Utils.elm:100-103`) is part of the same shape.
- **Fix shape (guess).** On the not-taken branch, when `saved` is `Just`, also void the existing measurement (no client-side delete path exists today), or refuse the checkbox while a value exists.
