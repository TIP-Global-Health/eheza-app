### B-573 — NCD initial phase: the Referral task counts as done when ANY referral record exists, so a hospital referral saved first in the recurrent phase (lab results) silently satisfies a pregnant hypertensive woman's ANC referral — READY · LOW · tier 4 · CONFIRMED (scout's scratch elm-test 5/5; orchestrator read all three anchors on ca8da2a33) · latent — needs the recurrent phase before the initial Next Steps in one open encounter AND pregnancy + hypertension · DEPLOYED, both sites · R53 unit 4
- **Mechanism.** The two phases of one encounter share a single `ncd_referral` measurement but decide completion differently:
  ```elm
  -- client/src/elm/Pages/NCD/Activity/Utils.elm:188-189 (nextStepsTaskCompleted, initial phase)
          TaskReferral ->
              isJust assembled.measurements.referral

  -- client/src/elm/Pages/NCD/RecurrentActivity/Utils.elm:94-98 (nextStepsTaskCompleted, recurrent phase)
          TaskReferral ->
              -- On recurrent phase of the encounter, only referral
              -- facility possible is hospital, since referral to ARV
              -- Services always happens on initial phase.
              referralToFacilityCompleted assembled FacilityHospital
  ```
  ```elm
  -- client/src/elm/Pages/NCD/Utils.elm:832-837 (resolveReferralInputsAndTasks)
          facility =
              if referForHypertension phase assembled && patientIsPregnant assembled then
                  FacilityANCServices
              else
                  FacilityHospital
  ```
  `referForHypertension NCDEncounterPhaseRecurrent` is always `False` (`:968-969`), so the recurrent phase refers to hospital; the initial phase refers a pregnant hypertensive woman to ANC. When the recurrent phase writes `{ReferToHospital, ReferralFormHospital}` first, the initial phase's `TaskReferral` sees a record and reads complete — the ANC referral form (and its accompany question) is never shown, Next Steps counts complete, End Encounter is allowed.
- **Reachability.** The labs entry is created when a test is saved as sent to the lab; the Case Management NCD Labs pane lists it on `resolutionDate` alone (`Pages/GlobalCaseManagement/View.elm:1487-1494`, no encounter-ended check), so same-day results → recurrent encounter page → Lab Results → recurrent Next Steps (referral for lab-found diabetes / renal with hypertension) → back to the still-open initial encounter → Next Steps. B-321 treats this same-day return as reachable but latent. The facilities differ only for pregnant + any hypertension stage (ihangane: 1 positive test + 6 known-as-positive pregnancy records ever, B-289 sizing).
- **Impact.** The ANC referral for a pregnant hypertensive woman is skipped; the progress report's `referralPhrase` picks ANC when pregnant (`ProgressReport/View.elm:594-599`) and prints "not referred to ANC services". Both sites. Tiny population.
