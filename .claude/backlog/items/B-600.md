### B-600 — Prenatal (CHW): a postpartum visit where the outcome was SAVED but the visit was left open cannot be reached on any later day; Postpartum then opens a second pregnancy — READY · MED-LOW · tier 3 · CONFIRMED by reading (B-574 / PR #2540 review round 1) · DEPLOYED, both sites · not sized · side-finding of B-574
- **Mechanism.** Saving Pregnancy Outcome closes the pregnancy at once (`ClosePrenatalSession` sets `endDate = Just currentDate`, `Backend/IndividualEncounterParticipant/Update.elm:32`). The participant page keeps a concluded pregnancy only on that same day:
  ```elm
  -- client/src/elm/Pages/Prenatal/Participant/Utils.elm (pregnancyConcludedInTodaysPostpartumVisit)
      (session.endDate == Just currentDate)
          && isJust session.outcome
          && List.any
              (\encounter ->
                  (encounter.encounterType == postpartumEncounterType)
                      && List.member encounter.endDate [ Nothing, Just currentDate ]
              )
              encounters
  ```
  On a later day `isPregnancyActive` is False and this keep rule fails, so no pregnancy is shown and the open postpartum visit is unreachable. The CHW's Postpartum tap creates a second pregnancy.
- **Reachability.** CHW → Postpartum → saves Pregnancy Outcome → leaves without ending the visit (danger signs, newborn link unsaved) → returns next day. The nurse has the same keep rule (`isChw` only picks the encounter type).
- **Distinct from B-574** (#2536 / PR #2540), which reopens a postpartum visit left before the outcome was saved. B-373 (fixed) is the same-day case.
- **Fix shape (first guess).** Keep a concluded pregnancy while this role's postpartum visit is still open, whatever day it was concluded. ⚠ Changes when a concluded pregnancy stops showing — a product call.
