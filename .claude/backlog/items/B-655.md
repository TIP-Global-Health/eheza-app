### B-655 — HIV and Tuberculosis e2e: the Case Management follow-up check is skipped when the filter button is missing, so a vanished pane leaves both tests green — READY · CONFIRMED by reading (orchestrator read both specs and the flag gates) · LOW · tier 4 · R75 unit 1 · tests only, no patient data
- **What is wrong.** Both CHW specs assert the follow-up in Case Management only if the filter button is visible at that instant:
  ```ts
  -- client/e2e/hiv-encounter-chw.spec.ts:88-95
      await navigateToCaseManagement(page);
      const hivFilter = page.locator('div.ui.segment.filters button', {
        hasText: /HIV/i,
      });
      // HIV filter is feature-flag dependent; only assert if visible.
      if (await hivFilter.isVisible({ timeout: 3000 }).catch(() => false)) {
        await verifyCaseManagementEntry(page, 'HIV', 'HIV', fullName);
      }
  ```
  `tuberculosis-encounter-chw.spec.ts:99-110` is the same with `/Tuberculosis/i`.
- **Why the condition cannot be legitimately false.** The same feature flag gates the encounter the test has just completed, so a test that reaches this line has the feature on:
  ```elm
  -- client/src/elm/Pages/IndividualEncounterTypes/View.elm:63-72
                      tuberculosisManagementButton =
                          if tuberculosisManagementEnabled features then
                              encounterButton TuberculosisEncounter
                      ...
                      hivManagementButton =
                          if hivManagementEnabled features then
                              encounterButton HIVEncounter
  ```
  The Case Management pane uses the same helpers (`Pages/GlobalCaseManagement/View.elm:156`, `tuberculosisManagementEnabled features`). So the `if` can only hide a regression. `isVisible` also does not wait (its `timeout` option is ignored), so a slow render skips the check too.
- **Reachability.** `e2e_playwright_2` (HIV) and `e2e_playwright_1` (Tuberculosis), every CI build.
- **Impact.** If the HIV or Tuberculosis filter or pane stopped rendering for a CHW, both tests stay green. The backend-node checks earlier in each test still run. Today the labels match and the check does run (scout's reading of the translations).
- **Fix shape (guess).** Drop the `if`; call `verifyCaseManagementEntry` unconditionally.
- **Related.** TH-21 / D1 is the same shape in the NCD recurrent spec (`ncd-encounter-nurse.spec.ts:448`), still present.
