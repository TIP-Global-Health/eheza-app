### B-255 — CHW progress report: the breech/transverse alert re-grades a stale exam against TODAY's gestational age, so a normal EGA-30 finding starts alerting once the pregnancy passes 32 weeks — READY · CONFIRMED (anchor + sibling family verified) · LOW · tier 4 · R25 unit 3
- **Mechanism.** `generateObstetricalDiagnosisAlertData` (`Pages/Prenatal/Encounter/Utils.elm`), branches `DiagnosisFetusBreech` and `DiagnosisFetusTransverse`: `resolveAlert` computes `egaInWeeks = calculateEGAWeeks currentDate lmpDate` and returns `Nothing` below 32 weeks — but the caller falls back to a **previous** encounter's exam (`if isJust assembled.measurements.obstetricalExam then resolveAlert assembled.measurements else resolveAlert lastEncounterMeasurements`) while still gating on today's EGA. The sibling family in `Backend/PrenatalActivity/Utils.elm` (`generateHighSeverityAlertData`, `FetalHeartRate` and `FetalMovement`) threads the date through — `resolveAlert ( date, measurements )` with `egaInWeeks = diffDays lmpDate date // 7`. This copy already has the date available (`getLastEncounterMeasurementsWithDate` returns it) and discards it via `getLastEncounterMeasurements`.
- **Reachability — the fallback is the ONLY live branch.** The sole consumer is `Pages/Prenatal/ProgressReport/View.elm:1231-1236`, guarded by `-- Alerts are displayed only for CHW. if isChw then`. On that path `assembled.measurements` belongs to a CHW encounter, which never has an `obstetricalExam` (CHW activity lists contain no `Examination`), so the `else` branch always runs.
- **Impact.** A breech or transverse presentation recorded at, say, EGA 30 — where it is normal and correctly suppressed — starts producing the alert line in the CHW progress report once today's EGA passes 32, from an exam that may be weeks old. False-positive direction only, never false-negative. All sites.
- **Fix shape (guess).** Use `getLastEncounterMeasurementsWithDate` and compute the EGA against the returned date in the fallback, matching the `FetalHeartRate`/`FetalMovement` siblings.
