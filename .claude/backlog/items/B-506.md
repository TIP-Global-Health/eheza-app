### B-506 — Completion builders: each of the seven history-reading builders decides on its own whether to skip saving, so a new builder can repeat the empty-history bug — READY · LOW · tier 4 · out of B-185 review round 2
- **Shape.** Acute Illness, Well Child, Child Scoreboard, NCD, HIV, TB and Prenatal each assemble history, compute and `node_save` in their own loops. B-185's fix had to add the same two guards to all seven:

  ```php
  -- server/hedley/modules/custom/hedley_reports/hedley_reports.module (each builder)
    // Return before loading measurements when every encounter already has data.
    if ($exclude_set && !hedley_reports_completion_data_missing($encounters)) {
      return;
    }
  ...
      if ($exclude_set && hedley_reports_completion_data_is_set($encounter)) {
        continue;
      }
  ```

- **Fix shape (guess).** Builders return per-encounter completion data; one shared writer skips encounters that already have data and saves the rest. Restructures seven builders, so it was kept out of the data-fix PR.
