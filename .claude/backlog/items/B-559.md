### B-559 — Prenatal Nutrition Assessment (sites without Healthy Start): re-saving the pregnancy's first weight compares it with itself, so a visit with no verdict on the first save shows and stores "severely inadequate" on any re-save — READY · CONFIRMED (code read 2026-11-05) · LOW · tier 4 · side-finding of B-556 (its review round 2, finding 1)
- **Mechanism.** With no pre-pregnancy weight on any LMP record, the baseline falls back to the oldest Nutrition weight, and the visit's own saved weight is in that list:
  ```elm
  -- client/src/elm/Pages/Prenatal/Activity/Utils.elm (resolvePrePregnancyWeight)
          -- As last resort - first weight measurement taken as
          -- part of Nutrition Assessment activity.
          byNutritionAssessmentWeight =
              let
                  current =
                      Maybe.map (\nutrition -> [ ( assembled.encounter.startDate, nutrition ) ])
                          assembled.measurements.nutrition
                          |> Maybe.withDefault []
          ...
              current
                  ++ nurseMeasurements
                  ++ chwMeasurements
                  |> List.sortWith sortTuplesByDate
                  |> List.head
  ```
  On the first save the visit has no saved measurement, so there is no baseline and no verdict. Once saved, a reopen or re-save (same day or later) takes the visit's own weight as the baseline: gain 0, ratio 0 → `GWGSeverelyInadequate`, and `SetGWGIndicator False` stores `inadequate-gwg` on the encounter, which the prenatal report counts.
- **Reachability.** The first prenatal Nutrition weight of a pregnancy with no LMP pre-pregnancy weight, re-saved. Not counted.
- **Impact.** Red verdict and a stored inadequate indicator for a visit where no gain can be judged. Sites without Healthy Start.
- **Fix shape (guess).** Exclude the visit's own weight when choosing the baseline for the form's verdict. ⚠ The progress report calls the same function for its chart baseline, where the first visit's own weight may be the intended baseline, so the change belongs at the form, or needs a report reading first.
