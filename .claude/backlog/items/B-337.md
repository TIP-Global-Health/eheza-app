### B-337 — NCD: renal complications found at the initial phase may hit the same omission diabetes did — the Stage 1 hypertension medication trigger and the referral both assume renal can only be diagnosed in the recurrent phase — READY-UNVERIFIED · noticed while building B-288, 2026-09-08 · needs the discovery seat's verification before it is presented
- **Where it came from.** While fixing B-288 I read the comment the fix sits next to:
  `Pages/NCD/Utils.elm` `medicateForHypertension`, Stage-1 arm —
  `-- Note that we do not check for Renal Complications, since it can only be diagnosed at recurrent phase.`
  That is the same class of assumption B-288 disproved for diabetes.
- **Why it may be false.** `matchNCDDiagnosis DiagnosisRenalComplications` is `renalComplicationsByCreatine assembled || renalComplicationsByUrineProtein assembled`, and both read the CURRENT encounter's measurements (`assembled.measurements.creatinineTest |> Maybe.andThen .creatinineResult`, `assembled.measurements.urineDipstickTest |> Maybe.andThen .protein`). Thirteen lab forms in `Measurement/Model.elm` carry an `immediateResult : Maybe Bool` field, so a point-of-care creatinine or urine dipstick looks possible on the same universal form the blood sugar uses.
- **What would be affected if so.**
  - `medicateForHypertension` Stage-1 arm — omits renal-at-current-encounter (it checks `diagnosedPreviouslyAnyOf (DiagnosisRenalComplications :: diabetesDiagnoses)` for previous encounters only).
  - `referForRenalComplications` initial arm — `diagnosedPreviously DiagnosisRenalComplications assembled.previousEncountersData` only.
  - ✅ NOT `expectNextStepsTask TaskHealthEducation` — that one already tests `DiagnosisRenalComplications` on the current encounter.
- ⚠ **Not verified.** I did not confirm that the NCD creatinine or urine dipstick forms actually offer the point-of-care option, nor size it on live. Do both before presenting: the diabetes half of this shape is live-sized at 8 affected encounters on ihangane (see [[B-288]]), so the question is worth answering either way.
- **Fix shape (guess).** If confirmed, the same swap B-288 made: read the diagnosis on the current encounter, not only on previous ones.
