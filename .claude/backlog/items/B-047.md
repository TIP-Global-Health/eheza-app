But `Backend/Nurse/Decoder.elm:25-40` reads neither `deleted` nor `status`; `Backend/Nurse/Encoder.elm:44` hardcodes `("deleted", bool False)`; the re-encode-on-save path (`SyncManager/Utils.elm` getDataToSendGeneral → bulkPut into `nodes`) therefore overwrites the local nurse row as live regardless of the tombstone. PIN gate (`nodes.js index()` ~:874-919, `{type,pin_code}` + `deleted == false`) then matches forever.
