- ⭐ **ROOT CAUSE (found 2026-08-17 by reading `hedley_migrate_generate_geo_terms_vocabulary()` + `_hedley_migrate_process_column()`, `hedley_migrate.module:300/365`): the generator identifies a location BY NAME, in two different broken ways.**
  - **(a) The dedup key is the RAW row path** (`implode('-', array_slice($row, 0, $index+1))`) **while the term name is normalised** (`ucfirst(strtolower(...))`). The CSV spells one Rulindo sector BOTH `Murambi` AND `MURAMBI` (proven: `awk` over `csv/geolocations_rwanda.csv`) ⇒ two terms, same name, same parent. **That IS 3847/3869.** The cell split follows from the same key: `MURAMBI` rows carry Bubangu+Gatwa+Mugambazi+Mvuzo (⇒ 3847, 4 cells), `Murambi` rows carry Bubangu only (⇒ 3869, 1 cell, 2 villages) — and Bubangu is duplicated across both.
  - **(b) The PARENT is resolved as `$data[$index-1][$parent_key]`, keyed by the parent's BARE NAME**, so a level holds one entry per name nationally. When a path repeats non-contiguously the early `return` skips re-seeding it and children attach to whichever same-named location came LAST. ⭐ **MEASURED by porting the PHP logic to Python and running it on the real CSV: as shipped (hierarchically sorted) 0 misparented; the SAME rows sorted by village ⇒ 227 MISPARENTED terms.** Row order was load-bearing and silently so.
  - **(c)** `implode('-')` keys collide for a name containing `-`; **(d)** no `trim`; **(e)** short/blank rows create nameless terms; **(f)** `hedley_migrate_generate_structure_for_terms_of_type()` interpolates the term name into Elm source UNESCAPED (a `\"` breaks compilation).
- **Fix: identity by normalised, escaped PATH** — `_hedley_migrate_geo_path_key()` = `implode('/', array_map('rawurlencode', lowercased path))`, used for BOTH the locator and the per-level map. That one change closes (a), (b) and (c) together, because dedup and parent resolution both stop being name-based. Plus `_hedley_migrate_geo_row()` (trim + skip-and-`watchdog` incomplete rows) and `addcslashes` on the Elm name. **Verified by re-porting the NEW logic: 2,775 terms, 0 duplicate paths, 0 misparented — in hierarchical, village-sorted AND reversed row order.**
