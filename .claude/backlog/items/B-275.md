### B-275 — Acute Illness subsequent visit: a positive-and-pregnant malaria RDT is not treated as "malaria diagnosed at this encounter", so an inapplicable health-education task is demanded — READY · CONFIRMED (anchors verified) · LOW · tier 4 · R26 unit 3
- **Mechanism.** `expectNextStepsTaskSubsequentEncounter` (`Pages/AcuteIllness/Activity/Utils.elm:2157-2158`): `malariaDiagnosedAtCurrentEncounter = malariaRapidTestResult measurements == Just RapidTestPositive`. Every sibling handles both positive variants — the subsequent-visit lab gate maps through `rapidTestPositive` (`:2010-2016`, helper `:2591-2593` = `List.member result [ RapidTestPositiveAndPregnant, RapidTestPositive ]`), and the subsequent-visit diagnosis branch maps `RapidTestPositiveAndPregnant` to `DiagnosisMalariaUncomplicatedAndPregnant` (`:2440-2445`). Both lines were written in the same commit (`a34173b21`, 2021).
- **Effect on task gating (`:2165-2190`).** For a pregnant positive on a subsequent visit: `NextStepsHealthEducation = not malariaDiagnosedAtCurrentEncounter` = **True** (False for a non-pregnant positive), so "Provided prevention education for Malaria Uncomplicated and Pregnant?" is required. `NextStepsSendToHC` falls into the `noImprovementOnSubsequentVisit` branch instead of `sendToHCByMalariaTesting` (which is True for `DiagnosisMalariaUncomplicatedAndPregnant`, `:2248`) — still True in practice, because fever is a precondition of the subsequent-visit malaria test (`:2008-2009`) and `sendToHCOnSubsequentVisitByVitals` (`:2302-2305`) reads the same `feverRecorded`. So the referral is not lost; the defect is one extra inapplicable task and a stored health-education record.
- **Reachability.** Any subsequent encounter (CHW or nurse) for a fertile woman with fever: `malariaTestingFormInputsAndTasks` (`:490-516`) asks the pregnancy question on every encounter, so `RapidTestPositiveAndPregnant` is savable on a subsequent visit; `assembled.diagnosis` is the encounter's diagnosis, updated on save (`Backend/Update.elm:9997`).
- **Impact.** Both sites. LOW — one wrong task; completion still navigates to the progress report.
- **Fix shape (guess).** `Maybe.map rapidTestPositive (malariaRapidTestResult measurements) |> Maybe.withDefault False`; pin with the TH-16 fixtures (TH-16 covers the diagnosis branch, not this gate).
