### B-414 — `admin/content` offers two bulk operations the code forbids outright, so running either throws an uncaught exception mid-batch — ✅ IMPLEMENTED 2026-10-07 (issue #2314, PR #2315 with B-334, branch `B-334-B-414-admin-menu-and-bulk-actions`, base `96ef7c454`) · CONFIRMED (scout read the export and both hooks) · LOW · tier 4 · R34 unit 6
- **Mechanism.** The exported VBO operation list enables a hard delete and an unpublish:
  ```php
  -- server/hedley/modules/custom/hedley_admin/admin_views_default/node.admin-content.inc:146-152
    'action::views_bulk_operations_delete_item' => array(
      'selected' => 1,
      'skip_confirmation' => 0,
      'override_label' => 1,
      'label' => 'Delete',
      'postpone_processing' => 0,
    ),
  ```
  (`action::node_unpublish_action` likewise at `:208`.) Both hit an unconditional throw:
  ```php
  -- server/hedley/modules/custom/hedley_admin/hedley_admin.module:230-237
  function hedley_admin_node_delete($node) {
    // Allow to override deletion restrictions.
    if (variable_get('hedley_super_user_mode', FALSE)) {
      return;
    }

    throw new Exception('Content deletion is forbidden!');
  }
  ```
  and `hedley_admin_node_update()` at `:211-222` throws `'Content unpublishing is forbidden!'` on any published→unpublished transition. `hedley_super_user_mode` is off by default and is in no strongarm export.
- **Reachability.** `admin/content`, the "Content list" link exported into `menu-eheza-app-admin-menu` and rendered for every administrator by `hedley_admin_block_view()` (`hedley_admin.module:172-200`). Select rows → Delete or Unpublish → uncaught exception (500) part-way through the batch.
- **Impact.** Admin-facing, all sites. No data loss — the throw is what prevents it — but the operation is un-runnable and fails ungracefully. The sanctioned "Mark as deleted" operation sits right beside them (`:153-159`).
- **Fix shape (guess).** Drop the two operations from `vbo_operations`, and consider whether `node_promote` / `node_make_sticky` mean anything here either.
- ✅ **Built 2026-10-07 — NOT the entry's fix shape.** Dropping the two operations from the export would also take them from super user mode, where the hooks allow them. Instead `hedley_admin_views_bulk_operations_form_alter()` removes them from `admin_views_node`'s dropdown unless `hedley_super_user_mode` is on (Form API then rejects a posted value not in `#options`). Only this view offers either operation. Not exercised in a browser.
