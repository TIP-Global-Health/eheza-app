- **Mechanism.** The non-universal lab form (NCD pregnancy and HIV tests only) clears the date and note when "performed" changes, but not `testResult`:
  ```elm
  -- client/src/elm/Measurement/Utils.elm:6652-6663 (contentAndTasksLaboratoryTestInitial)
          boolInputUpdateFunc =
              \value form_ ->
                  { form_
                      | testPerformed = Just value
                      ...
                      , executionNote = Nothing
                      , executionNoteDirty = True
                      , executionDate = Nothing
                      , executionDateDirty = True
                  }
  ```
  `PregnancyTestForm` has no `testResultDirty` (`Measurement/Model.elm:1704-1716`), and hydration refills the saved result:
  ```elm
  -- client/src/elm/Measurement/Utils.elm:3287, 3299-3306
                  , testResult = or form.testResult value.testResult
  ...
              { executionNote = executionNote
              , executionDate = form.executionDate
              , testResult = form.testResult
  ```
  The result input is hidden once "performed" is No, and the form counts complete without it. The known-as-positive update (`:6433-6461`) has the same gap. `HIVTestForm` (`:2419`) is the same.
- **Reader trusts the result before the note:**
  ```elm
  -- client/src/elm/Pages/NCD/Utils.elm:1002-1015 (patientIsPregnantAtEncounter)
                          if (value.executionNote == TestNoteKnownAsPositive) || (value.testResult == Just TestPositive) then

                              Just ( False, answerDate )

  ```
- **Harm, both directions.** Stale Negative under "lack of reagents" overrides an earlier Positive → not pregnant → full antihypertensive list incl. ACE inhibitors (the case B-289's round-3 fix meant to prevent). Stale Positive → Methyldopa only + ANC referral. Uses: `NCD/Utils.elm:413, 622, 672, 831, 962`; `NCD/Activity/Utils.elm:148`.
- **Scouts' run evidence:** saved Run-today/Negative → performed=No + Lack of reagents → `toPregnancyTestValueWithDefault` stores `testResult = Just TestNegative`; `patientIsPregnant` with that + a Positive two months earlier → **False**; Lack of reagents + Positive, no history → **True**.
- **HIV sibling:** a stale Positive under a why-not note counts in the NCD dashboard's patients with HIV (`hedley_stats.module:1397-1416` → `Pages/Dashboard/Utils.elm:1776-1795`, reads `testResult` with no note check).
