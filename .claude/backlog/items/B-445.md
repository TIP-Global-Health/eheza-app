### B-445 — Statistical Queries › ANC Contacts: postpartum encounters count as ANC contacts when the delivery came before the EDD, unlike the "at least N contacts" rows ten lines below — READY · VERIFIED (orchestrator read both blocks) · MED-LOW · tier 3 · DEPLOYED · 774 live encounters on ihangane
- **Found R38 unit 4** (Statistical Queries cross-side). Sibling blocks disagree on one filter.
- **Mechanism.** The per-contact rows count every encounter of the pregnancy dated on or before LMP + X weeks:
```elm
-- server/elm/src/Pages/Reports/View.elm:2395-2416
        countPregnanciesByContacts ( numberOfContacts, egaWeeks ) =
            List.filter
                (\( lmpDate, pregnancy ) ->
                    let
                        egaXDate = Date.add Days (egaWeeks * 7) lmpDate
                        encountersBeforeEGAX =
                            List.filter (\encounter -> not <| Date.compare encounter.startDate egaXDate == GT)
                                pregnancy.encounters
                    ...
                        && (List.length encountersBeforeEGAX == numberOfContacts)
```
  while the "at least N contacts" rows exclude postpartum visits:
```elm
-- server/elm/src/Pages/Reports/View.elm:2434-2440
                            nonPostpartumEncounters =
                                List.filter
                                    (\encounter -> not <| List.member encounter.encounterType [ NursePostpartumEncounter, ChwPostpartumEncounter ])
                                    pregnancy.encounters
```
  The wire carries the encounter type for every encounter (`hedley_reports.module:974-976, 1015`; `prenatalEncounterTypeFromString`, `Backend/Reports/Decoder.elm:280-303`), so the data to exclude them is present. A pre-term delivery followed by a postpartum visit before the EDD adds one "contact" to the 36/38/40-week rows, and because the rows test `== numberOfContacts` it can also move a pregnancy out of its true row.
- **Reachability.** Admin › Statistical Queries › ANC Contacts: rows "First ANC contact (≤12 weeks)" … "8th ANC contact (40 weeks)" and "Pregnant women who attended ANC contact within 1st trimester".
- **Impact.** All sites, no `EHEZA_SITE` split. Live (scout, ihangane.live 2026-09-29): **774** non-deleted postpartum encounters dated before their pregnancy's EDD, **491** of them more than 4 weeks before (so they reach the 36-week row too).
- **Evidence.** Both blocks read; live count run. The exact-equality semantics of the rows themselves is the spec question B-133 lists and is untouched here.
- **Fix shape (guess).** Filter postpartum encounter types out of `pregnancy.encounters` once, before both blocks.
