### B-444 — Prenatal HIV PCR: a viral load corrected to "undetectable" keeps the number typed before, and the diagnosis reads the number alone, so a suppressed result is diagnosed as a detectable viral load — READY · VERIFIED (scout scratch elm-test 8/8 through the real updates, value builders and `generatePrenatalDiagnosesForNurse`; orchestrator read all three handlers, hydration, value builders, predicate, both report readers, and `origin/main`) · MED-LOW · ⭐ tier 1 (diagnosis determination) · DEPLOYED (`origin/main` identical) · 0 live instances on ihangane today
- **Found R38 unit 2** (Prenatal lab-form writers). Same family as [[B-421]] / [[B-440]]: a status change that does not clear its dependent field, and a reader that trusts the dependent field.
- **Mechanism.** The status toggle writes only the status, in all three handlers, although the form carries a `hivViralLoadDirty` flag:
```elm

            ...

                    { form | hivViralLoadStatus = Just status, hivViralLoadStatusDirty = True }
-- client/src/elm/Pages/Prenatal/RecurrentActivity/Update.elm:756-769 (recurrent, nurse and lab tech; same at 1669-1682 labs history)
                updatedForm =
                    { form | hivViralLoadStatus = Just status }
```
  The load input is rendered only while the status is Detectable (`Measurement/Utils.elm:6092-6118`), so after tapping Yes the number vanishes and the task counts complete. Hydration keeps a typed value (dirty) or refills the saved one, and both value builders store it unconditionally:
```elm
-- client/src/elm/Measurement/Utils.elm:3205-3208, 3226-3227 (hivPCRTestFormWithDefault / toHIVPCRTestValue; result form same at ~8201-8237)
                , hivViralLoad = maybeValueConsideringIsDirtyField form.hivViralLoadDirty form.hivViralLoad value.hivViralLoad

            , hivViralLoadStatus = form.hivViralLoadStatus
            , hivViralLoad = form.hivViralLoad
```
  The diagnosis reads the number and ignores the status:
```elm
-- client/src/elm/Pages/Prenatal/Activity/Utils.elm:2282-2286, 2756-2761
        hivDetectableViralLoadDiagnosed =
            getMeasurementValueFunc measurements.hivPCRTest

...

            hivDetectableViralLoadDiagnosed && immediateResult .hivPCRTest
```

  while the lab-results pane reads the status first and shows the same record as suppressed (`Pages/Report/View.elm:961-970`). The progress-report treatment line (`Pages/Prenatal/ProgressReport/View.elm:2627-2629`) is status-blind like the predicate.
