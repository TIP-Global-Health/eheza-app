```elm
-- server/elm/src/Pages/Scoreboard/View.elm:82-84 (a867bc2b6; same test at :198, :277, :358, :523, :709, :817, :977)
                                    existedDuringExaminationMonth =
                                        -- Making sure patient was already created during examination month.
                                        Date.compare record.created targetDateForMonth == LT
```

- **Impact.** One day per child: registered 2026-09-30 → missing from September's numerators and denominator; registered today → missing from the current column. Numerator and denominator both drop the child, so percentages move only slightly.
