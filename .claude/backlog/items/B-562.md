### B-562 — Prenatal and NCD labs entry: ordering a test, declining a pending test, Wait and review still write the entry whole from the device's copy, so a behind device drops another device's follow-up tests and review state — READY · LOW · tier 4 · CONFIRMED (code; R47 counts: `tests_with_follow_up` dropped 7, `review_state` 22 on the ihangane copy) · DEPLOYED · the remainder B-493 / PR #2442 and B-519 / PR #2446 left out · R51 unit 2
- **Mechanism.** PRs #2442 and #2446 rebuild `performedTests` / `completedTests` from the device's measurements before the "result added" and conclude saves (`withCompletedTestsFromMeasurements`, `Pages/Prenatal/RecurrentActivity/Utils.elm:156-241`, `Pages/NCD/RecurrentActivity/Utils.elm:215-233`). Every other labs-entry writer still PATCHes the cached value whole:
  ```elm
  -- client/src/elm/Backend/Measurement/Utils.elm:1498-1534 (labsResultsTestAddedMsgs)
              if not testExecuted && not (EverySet.member test value.performedTests) then
              ...
                      performedTests =
                          if testExecuted then
                              EverySet.insert test value.performedTests
                          else
                              EverySet.remove test value.performedTests
              ...
                          | performedTests = performedTests
  ```
  It is reached when a test is ordered or marked not performed (`Backend/Update.elm:2191-2206`: `resultsAdded` false → `generatePrenatalLabsTestAddedMsgs`), and `testsWithFollowUp`, `patientNotified` and (while tests remain) `reviewState` come from the cached copy in every save, the two repaired ones included. The queued body is frozen at save time (`nodes.js:260-290`) and uploads verbatim after a newer server copy was downloaded.
- **Reachability.** A nurse marks a pending test "not performed" on a device whose labs-entry copy is behind the lab tech's; or any result save on a device that missed the lab tech's `testsWithFollowUp` write.
- **Impact / size.** All sites, low volume: B-493's R47 re-measure on `ihangane_post` found `review_state` dropped 22 times and `tests_with_follow_up` 7; NCD twin 0. A dropped follow-up test disappears from the lab tech's list; a dropped review state re-opens a reviewed entry.
- **Already recorded, distinct.** B-493 and B-519 are the delivered halves (two test sets on the result-added and conclude saves); B-524 is the participant/encounter whole-copy PATCH class; B-520 reads the same sets for "second phase required". The frozen-body upload itself is the design brief's per-record-commit territory, not this item.
- **Fix shape (first guess).** Route `labsResultsTestAddedMsgs` through the same measurements-based rebuild, and union `testsWithFollowUp` with the follow-up tests derivable from the measurements before every PATCH; Prenatal and NCD together.
