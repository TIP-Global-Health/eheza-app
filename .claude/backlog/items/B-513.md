### B-513 — Statistical Queries per-person data: a measurement saved while the person's recalculation is already running is never re-queued, so the stored report misses it until some later save — READY · LOW · tier 4 · CONFIRMED (code + ihangane copy, 2026-10-26) · DEPLOYED (all sites)
- **Mechanism.** The enqueue helper treats a PROCESSING item as "will cover this save":

  ```php
  -- server/hedley/modules/custom/hedley_general/hedley_general.module (origin/main f851e440d), hedley_general_advanced_queue_task_exists()
      if ($task->status == ADVANCEDQUEUE_STATUS_PROCESSING) {
        if (time() - $task->created < variable_get('hedley_aq_task_max_processing_period', 20 * 60)) {
          // Task is being processed, and did not exceed allowed time period,
          return TRUE;
  ```

  but `hedley_reports_calculate_aggregated_data_worker` has already read the person's measurements when the item was claimed. An upload batch that spans the claim (encounter saved → item claimed → height/weight inserted a second later) is dropped from `field_reports_data`, and nothing re-queues the person until another save.
- **Live instance (ihangane copy 2026-10-26).** Person 5163277: reports item 640844 created 2026-05-26 11:54:52, processed 11:54:56; `well_child_height` 5557181 and five sibling measurements created 11:54:53 by robot 4434; stored wire for the 2026-05-22 well-child encounter is `2026-05-22|,,,,|` (no z-scores). Scout traced two more (5528895, 5536025). Rate on the post copy: 2 of 15,131 child-month height pairs in the 12-month window; Bumbogo May 2026 stunting denominator 158 stored vs 159 recomputed; every other month matches.
- **Impact.** Statistical Queries nutrition tables and diagnosis rows, both fleets; small and self-healing on the person's next save. Not a diagnosis-path defect.
- **Fix shape (first guess).** Deduplicate on QUEUED only (re-queue when the existing item is PROCESSING; the worker is idempotent), or stamp the read time on the item and let a later save compare. Adjacent, not the same: B-086 (stuck-task window), B-096 (release timeout, SKIPPED).
