### B-651 — WhatsApp progress report: the sent image loses the no-photo baby icon, and sometimes the Lato font, because the screenshot step resolves stylesheet images and fonts against the wrong address — READY · LOW-MED · tier 4 · CONFIRMED (404s seen in the QA run of pull request 2585; two sent PNGs inspected; cause read in code, fix not tried) · DEPLOYED, every site with `report_to_whatsapp` · side-finding of the QA run of pull request 2585, 2026-11-24
- **What the patient gets.** For a child with no photo, the report's photo square is plain grey: the baby outline is missing. In one of two sent images the patient-detail values ("10 months", the birth date) fall back from Lato to another font.
- **Evidence.** `server/www/sites/default/files/private/whatsapp-upload-62138728.png` (icon missing, fallback font) and `whatsapp-upload-69465999.png` (icon missing, Lato present). Both are local, untracked files.
- **Mechanism.** `makeProgressReportScreenshot` in `client/src/js/app.js` passes html2canvas an `onclone` that downloads each stylesheet again and pastes its text into the cloned page as an inline `<style>`:
  ```js
  var promise = fetch(styleSheet.href, { cache: 'reload' })
    ...
    .then(function(cssText) {
      var style = document.createElement('style');
      style.textContent = cssText;
      document.head.appendChild(style);
    })
  ```
  The stylesheets use relative addresses (`$img-path: '../images/'`, `url('../fonts/lato-v14-latin-*.woff2')`, Semantic's `url(themes/default/assets/fonts/icons.woff)`). In a `<style>` block these resolve against the page (`/`), not the stylesheet, so they become `/images/…`, `/fonts/…`, `/themes/default/…`, and all return 404.
- **Why the font comes and goes.** The original stylesheets are still in the clone, so a font already cached by the normal page can still render. Whether it does depends on what was loaded earlier in the session.
- **Reproduce.** Open a child's progress report, Send via WhatsApp, consent and a number, tick a section, Continue, Send; watch the network log for the 404s. Same on develop.
- **Fix shape.** Before inserting each stylesheet's text, rewrite its relative `url(...)` values to absolute ones based on `styleSheet.href` (`new URL(path, styleSheet.href)`). Or drop the re-download if html2canvas no longer needs it; check why it was added first.
- **Not covered elsewhere.** B-027 (PARKED) is about failure paths in the same step with no completion event; it does not cover these addresses.
- **Seen but not part of this item.** The 12:40 image stops after the immunization table headings, while the 12:30 image of the same child has all seven rows. Not investigated; it may come from the QA run's own setup.
