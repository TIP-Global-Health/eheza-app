### B-396 — `e2e_playwright_1` joins its two Playwright runs with `&&`, so any failure in the first leg silently skips the other 25 tests — 🅿 PARKED by user 2026-10-08 — verbatim: "we run the tests to verify no regressions in development. If one test fails, it's enough to stop and solve it. If all pass, we're good anyway. Why should we insist on running more tests if we know one has failed?" — then "yes, park it". Do NOT re-pitch. · was READY · CONFIRMED (scout read the step metadata and both a red and a green build's output; orchestrator re-measured the two legs) · MED · tier 3 · R34 unit 3
- **Mechanism.**
  ```yaml
  -- .circleci/config.yml:156-159
        - run:
            name: Run E2E tests
            command: cd client && export TZ=UTC && npx playwright test prenatal tuberculosis && npx playwright test --grep-invert "Well Child|NCD|HIV|…"
  ```
  CircleCI runs each step under `#!/bin/bash -eo pipefail`. Leg A selects 11 tests, leg B selects 25 (orchestrator re-measured both with `playwright test --list`). When leg A exits non-zero, leg B never runs, and the job's output shows only leg A's counts.
- **Evidence.** Red build 30850 prints exactly one `Running 11 tests using 1 worker` block, then `1 failed / 10 passed`, then `Exited with code exit status 1` — no second `Running N tests`. Green build 30881 on the same job prints both blocks, 11 then 25.
- **Impact.** Whenever leg A fails — including on the two recorded flakes [[B-379]] and [[B-380]] — **25 of the suite's 65 tests do not run**, and the job looks like "one flaky test". The habitual response, retriggering with an empty commit, is right only by luck: it re-runs everything, but nobody is told that 38% of the suite was skipped. Today this is what hides two of the four stale literals in [[B-395]].
- **Fix shape (guess).** Run both legs unconditionally and fail if either did — either two separate `run` steps, or one step with an exit-code accumulator instead of `&&`.
- 🅿 **PARKED 2026-10-08.** Fail-fast lets no regression through: a red job blocks the merge, and the fix-or-rerun runs all 36 tests. The change would only save CI round trips when several tests fail at once.
