### B-324 — Acute Illness diagnosis: on a site without Tuberculosis Management, a COVID-suspect patient with a cough of more than two weeks can never be diagnosed with COVID — the COVID path exits "to diagnose TB suspect" unconditionally, but TB suspect is only diagnosed when the feature is on, so the encounter falls through to Fever of Unknown Origin / complicated RI / GI with a positive COVID RDT on record — ✅ IMPLEMENTED 2026-09-08 · issue #2217, PR #2218 · CONFIRMED (both paths, the lab gate, the writer and both introducing commits read by the orchestrator) · MED-LOW · tier 1 (diagnosis rule) · R29 unit 1 · ⭐ DEPLOYED, tip-somalia only — live-sized 2026-09-08: tip-somalia has ZERO acute illness encounters, so it has never fired
- **Mechanism.** The initial-encounter resolver (`client/src/elm/Pages/AcuteIllness/Activity/Utils.elm:2434-2446`) tries `covid19DiagnosisPath` first and falls back to `nonCovid19DiagnosisPath`. The COVID path (`:2503-2514`) returns `Nothing` when `isChw || not covid19SuspectDiagnosed || coughForMoreThan2Weeks measurements`, with the comment *"we must diagnose Tuberculosis suspect. Therefore, we need to exit COVID19 path"* — it does not receive `features`. The non-COVID path (`:2616-2624`) diagnoses `DiagnosisTuberculosisSuspect` only when `tuberculosisManagementEnabled features && coughForMoreThan2Weeks`; otherwise, because COVID suspicion requires fever (`covid19SuspectDiagnosed :2491-2497`), it goes to `resolveAcuteIllnessDiagnosisByMalariaRDT` (`:2653-2672`), whose RDT is non-positive by construction → `DiagnosisRespiratoryInfectionComplicated` / `DiagnosisGastrointestinalInfectionComplicated` / `DiagnosisFeverOfUnknownOrigin`. The COVID RDT task is still offered (`LaboratoryCovidTesting -> not isChw && covid19SuspectDiagnosed`, `:2021-2023`), so the nurse can record a positive COVID RDT the engine cannot act on. History: the exit was added unconditionally in `ab3d0f982` (2024-03-13); the feature gate was added to the sibling path only, eight days later, in `b05e10417` (2024-03-21) — a copy-adapted pair where one half was not updated.
