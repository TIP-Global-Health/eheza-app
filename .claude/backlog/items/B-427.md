### B-427 — Child Scoreboard NCDA scorecard: the three "6–24 months" nutrition-behaviour rows and the Breastfed row show a red X for months 0–5, where the questionnaire never asks the question — READY · CONFIRMED (orchestrator read the row builders, the cell resolver, the form step gate and the shipped precedent) · MED-LOW · tier 3 · R36 unit 2 · DEPLOYED (Rwanda, `ncda`)
- **Mechanism.** The rows resolve a month with a questionnaire to V or X by sign membership, and only a month with no questionnaire becomes a dash:
  ```elm
  -- client/src/elm/Pages/WellChild/ProgressReport/View.elm:1979-1989
          appropriateComplementaryFeedingValues =
              generateValues currentDate child allQuestionnairesByAgeInMonths
                  (.signs >> EverySet.member Backend.Measurement.Model.AppropriateComplementaryFeeding)
          diverseDietValues = generateValues ... (.signs >> EverySet.member FiveFoodGroups)
          mealsADayValues = generateValues ... (.signs >> EverySet.member MealsAtRecommendedTimes)
  -- :3121-3131 (generateValues)
                          Dict.get month values
                              |> Maybe.map (\value -> if resolutionFunc value then NCDACellValueV else NCDACellValueX)
                              |> Maybe.withDefault NCDACellValueDash
  ```
  The three signs live on the Nutrition Behavior step, which the form omits under six months (single gate, one caller):
  ```elm
  -- client/src/elm/Measurement/Utils.elm:9508-9511 (resolveNCDASteps)
          NCDAStepNutritionBehavior ->
              ageInMonths currentDate person
                  |> Maybe.map (\ageMonths -> ageMonths >= 6)
  ```
  so every questionnaire taken before six months lacks the signs and reads as "No"; the month-0..5 cells never heal. The Breastfed row (`:1996-2020`) paints X on months 0–5 whenever no questionnaire yet carries `BreastfedForSixMonths`, a question asked only from six months (`Measurement/View.elm:3225-3233`); that one self-corrects later.
- **Why a defect.** The row label says "Appropriate complementary feeding (6-24 mo)" (`Translate.elm`), the file already dashes too-young months for the medicine rows (`postProcessMedicineRawValue`, `:2541-2550`), and B-067 (implemented) established that a question not asked is a dash, not an X. These four rows were not swept with it.
- **Reach.** Child Scoreboard → progress report → NCDA scorecard (also the Well Child / Nutrition report tab, shared `viewProgressReport`); the CS NCDA activity is unconditional (`Pages/ChildScoreboard/Activity/Utils.elm:32-34`), so any infant visited monthly has questionnaires from birth. Display only, incl. the WhatsApp copy. Server aggregation counts positives only, so it is not affected (denominators are B-428).
- **Fix shape (first guess):** dash months below 6 for the three rows (reuse the medicine-row idea) and give the Breastfed row a "not yet asked" state distinct from "No".
