### B-542 — Completion report: every generator orders a participant's encounters by `nid` and treats the lower nids as the history, so when a CHW and a nurse device interleave uploads the earlier visit can be computed against a later one's history (first-visit flag, inherited diagnosis, vaccination and lab recency) — READY · LOW · tier 4 · CONFIRMED (code; rare: 14 of 2,485 prenatal, 6 of 5,785 well-child, 0 of 1,343 acute-illness participants since 2025) · DEPLOYED · completion family (B-178..B-185 usage gate) · R49 unit 1
- **Mechanism.**
  ```php
  -- server/hedley/modules/custom/hedley_reports/hedley_reports.module:3746-3753 (acute illness; same block at 4775, 5094, 6284, 6583, 6786, 7340, 7497, 7714)
    // Load all encounters of current participant.
    $query = hedley_general_create_entity_field_query_excluding_deleted();
    $result = $query
      ->entityCondition('entity_type', 'node')
      ->entityCondition('bundle', 'acute_illness_encounter')
      ->propertyCondition('status', NODE_PUBLISHED)
      ->fieldCondition('field_individual_participant', 'target_id', $participant->nid)
      ->propertyOrderBy('nid')
      ->execute();
  ```
  Each generator then slices `array_slice($encounters_data, 0, $index)` as "previous encounters" (acute illness: `is_initial`, inherited diagnosis, prior malaria/medication; well child: vaccination history, ECD signs, last medication; NCD: first-encounter history activities, lab recency; HIV, TB, child scoreboard; prenatal: previous nurse encounters — LMP, diagnoses so far, labs, treatment). `nid` is arrival order; `field_scheduled_date` is the clinical order.
- **Reachability.** Nightly Jenkins completion scripts (`hedley_reports/scripts/completion-generate-*.php`, callers only — the logic is in the module) → `field_reports_data` on encounters → `HedleyRestfulReportsData` → Completion report. With `--exclude_set` the already-computed later encounter is never recomputed, so the wrong expected set sticks.
- **Size.** Orchestrator re-ran the prenatal count: 14 participants with ≥ 2 encounters since 2025 where nid order ≠ `field_scheduled_date` order (of 2,485). Real but rare; completion percentages only.
- **Fix shape (first guess).** Sort the loaded encounters by `field_scheduled_date` with `nid` as tie-break before building `$encounters_data`, in one shared helper used by all nine generators.
