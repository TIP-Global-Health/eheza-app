### B-611 — Person upload: every character outside `a-z A-Z 0-9 _ space -` is silently deleted from first and second names ("Désiré" is stored "Dsir", "N'Gabo" "NGabo") and the stripped name downloads back over what was typed — READY · CONFIRMED by reading (orchestrator read the rule and its requirement trail; not run, not sized) · ⚠ INTENT QUESTION — the rule is deliberate · tier 4 · DEPLOYED since 2023-07, all sites · R58 unit 2
- **Mechanism.**
  ```php
  // server/hedley/modules/custom/hedley_restful/plugins/restful/node/sync/HedleyRestfulSync.class.php:393-397, 490-493
  $freeTextFields = [
    'label',
    'first_name',
    'second_name',
  ];
  ...
  elseif (in_array($key, $freeTextFields) && !empty($value)) {
    // Verify there are only plain characters at patient name.
    $data[$key] = trim(preg_replace('/[^a-zA-Z0-9_ -]/s', '', $value));
  }
  ```
  The title is rebuilt from the stripped fields (`hedley_person.module` ≈1149-1154), the node gets a new vid, and the stripped name comes back to the device.
- **Reachability.** Person create and edit. The client puts no character restriction on these inputs (plain `viewTextInput` in `Pages/Person/View.elm`; `Backend/Person/Form.elm` only trims), so the nurse sees the accent accepted and later sees a different name.
- **Impact.** Patient identity text changed with no error and no trace of the original; heaviest where French given names carry accents (Burundi, also Rwanda). A name made only of stripped characters becomes empty with no rejection. `spouse_name` / `next_of_kin_name` are not stripped, so the rule is uneven. The `'label'` entry is dead (`label` is in `$ignoredFields`).
- **Intent.** Deliberate: commit `d3eb00f54` (2023-07-30, PR #807 "Sanitize patient name"), whose body links `Gizra/ihangane#3060` — "Resolve sync error on Bikamba village CHW 2", two screenshots, no text (orchestrator read it). So the rule was a fix for a sync error caused by a name, not a requirement that names be ASCII. What the offending character was is not recorded.
- **Question for the user.** Keep deleting, or transliterate (é → e) / validate on the client so the nurse sees what will be stored? Not sizable after the fact — the removed letters are gone.
- **Fix shape (guess).** Transliterate instead of delete, or mirror the rule in the form's validation.
