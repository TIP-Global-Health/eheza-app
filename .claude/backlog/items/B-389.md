### B-389 — A live uvl village carries a sector name that is not in the geo table, and nothing validates it: a CHW assigned there could register nobody and could not see why — READY · CONFIRMED (orchestrator byte-checked the live value against its four siblings and the dict) · LOW-MED · tier 4 · R33 unit 4 · latent (0 nurses on that village), uvl + ihangane
- **Mechanism.** Village node 21 on uvl, `Nyamugari at Nyamugari`, stores `field_sector = "Nyagasaga"`. Its four siblings under the same sector and the Burundi dict all spell it `Nyagasasa`:
  ```
  nid  title                              sector       HEX
  19   Ruhinga at Ruhinga                 Nyagasasa    4E7961676173617361
  21   Nyamugari at Nyamugari             Nyagasaga    4E7961676173616761   <-- one character
  23   Nyakigano at Nyakigano             Nyagasasa    4E7961676173617361
  ```
  ```elm
  -- client/src/elm/GeoLocation/Utils.elm:217
          , ( toEntityId 72, GeoLocation "Nyagasasa" (Just <| toEntityId 47) )
  ```
  This is B-151's class relocated from the dict into customer data.
- **The path that breaks is CHW registration.** `applyDefaultValuesForPerson` derives the address by chained name→id lookups (`Backend/Person/Form.elm`): `"nyagasaga"` is not under district Matana, so `defaultSectorId = Nothing`, and cell and village follow. `Pages/Person/View.elm` hides the whole address UI for a CHW (`addressSection = if isChw then [] else ...`), while `validatePerson` requires all five. For a new adult (relation `Nothing`) the `withDefault (Maybe.andThen .sector related)` fallback cannot fire, so `Form.getOutput = Nothing` and Save does nothing. The nurse sees a `ValidationErrors` box naming Sector / Cell / Village — fields the CHW form never renders, so there is no way to act on it.
- **Reachability / sizing (orchestrator live).** Today village 21 has 0 nurses, 0 residents and an empty auto-created CHW clinic; 14 of uvl's 22 villages have nurses and 21 is not one of them. ihangane has the same shape at village level — nids 215977, 3535682, 3560143 are not in the Rwanda dict, all with 0 nurses. One nurse assignment away from firing.
- **Fix shape (guess).** Two separable things: correct the one live value (ops), and close the gap that let it in — the village node form takes free text with no check against the geo table, and `migrate-villages.php` neither trims nor validates. A presave check that the five names resolve as a chain would catch this and [[B-388]]'s blank-field case in one place.
