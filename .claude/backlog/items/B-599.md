- **Mechanism.** The initial-phase rule needs 160 / 110 or above:
  ```elm
  -- client/src/elm/Pages/Prenatal/Activity/Utils.elm (moderatePreeclampsiaByMeasurementsInitialPhase)
      highBloodPressure measurements
          && (highProtein || edemaOnHandOrLegs measurements)
  ```
  The recurrent rule takes a borderline first reading only through the repeated one:
  ```elm
  -- client/src/elm/Pages/Prenatal/Activity/Utils.elm (moderatePreeclampsiaByMeasurementsRecurrentPhase)
      (highBloodPressure measurements && highProtein)
          || (repeatedTestForMarginalBloodPressure measurements
                  && (edemaOnHandOrLegs measurements || highProtein)
             )
  ```
  After #2527 the two-hour recheck is skipped once hypertension or moderate preeclampsia was diagnosed earlier (clinician, spec #256, 2022-05-20: "No need to do the 2-hour wait once hypertension has been diagnosed!"), so `diaRepeated` / `sysRepeated` stay empty and the second branch can never fire.
- **Reachability.** Visit 1: Gestational Hypertension. Visit 3: 150 / 95, urine protein high or edema → no Moderate Preeclampsia; the hypertension treatment pathway continues.
- **Question for the clinician.** For a woman already diagnosed with hypertension, should a borderline FIRST reading plus protein / edema diagnose Moderate Preeclampsia (no recheck), or should the recheck run in that case only?
- **Related, same review (scope points declined on #2527, clinical calls):** earlier Severe Preeclampsia / Eclampsia, and hypertension reported through Outside Care (`pastDiagnoses`), do not block the recheck — consistent with every hypertension diagnosis gate today, which read visit diagnoses only.
- **Fix shape (first guess).** In the recurrent-phase or initial-phase rule, accept the first reading when hypertension was diagnosed previously — pending the clinician's answer.
- 📜 **Intent answered by the spec (read 2026-11-16).** #139 (preeclampsia spec), clinician 2022-03-21: "once a diagnosis of hypertension or preeclampsia is confirmed, there is no need to wait 2 hours and repeat a blood pressure. So for a known hypertensive the first borderline reading counts as confirmed; the code never built that pathway for Moderate Preeclampsia.
