### B-470 — Antenatal progress report › Medical Diagnosis: a moderate-anemia line reads "no treatment recorded" although the nurse answered the reinforce-Fefol/MMS and repeat-Hb questions — the arm still looks for Iron and Folic acid, which the form stopped offering in July 2025 — READY · CONFIRMED (orchestrator read writer, value builder, report arm and blame; `112b6c251` is in `origin/main`; live ihangane 226 moderate-anemia encounters since the deploy, 9 medication records with reinforce answers) · MED · tier 3 · R41 unit 1 · DEPLOYED both sites
- **Found R41 unit 1** (Prenatal writers ↔ display readers). Silent regression: pre-2025 records still render as before.
- **Mechanism.** The report renders the moderate-anemia line from Iron + Folic acid in `distributionSigns`:
```elm
-- client/src/elm/Pages/Prenatal/ProgressReport/View.elm:2784-2815
        DiagnosisModerateAnemiaInitialPhase ->
            getMeasurementValueFunc measurements.medicationDistribution
                |> Maybe.andThen
                    (\value ->
                        ...
                        Maybe.map2
                            (\ironTreatmentMessage folicAcidTreatmentMessage -> ...)
                            (treatmentMessageForMedication value.distributionSigns nonAdministrationReasons Iron)
                            (treatmentMessageForMedication value.distributionSigns nonAdministrationReasons FolicAcid)
                    )
                |> Maybe.withDefault noTreatmentRecordedMessage

        DiagnosisModerateAnemiaRecurrentPhase ->
            viewTreatmentForDiagnosis language date measurements allDiagnoses DiagnosisModerateAnemiaInitialPhase
```
  `customTreatmentMessageForMedication` (`:2550-2568`) is `Just` only when the medication is in `distributionSigns` or has a non-administration reason, so `map2` yields `Nothing` → "<diagnosis> on <date> - no treatment recorded". The writer no longer offers Iron/Folic acid: `resolveRequiredMedicationsSet` has no anemia set, and moderate anemia goes through `resolveReinforceTreatmentForAnemia` (`Pages/Prenatal/Utils.elm:815-823, 912-976`), whose three questions are saved as `reinforceTreatmentSigns` (`:700-714`: `ReinforceSignFefol / ReinforceSignMMS / ReinforceSignRepeatHemoglobinTest`, `NoReinforceTreatmentSigns`). `Iron`/`FolicAcid` survive in `Pages/Prenatal/Utils.elm` only as hydration (`:559-560, :583-584`) and value building (`:675`); no input sets them. Nothing in `Pages/Prenatal/ProgressReport/*` or `Pages/Report/*` reads `reinforceTreatmentSigns` (grep: 0 hits).
- **Reachability.** Nurse → initial or recurrent encounter → Hb → `DiagnosisModerateAnemia{Initial,Recurrent}Phase` → Next Steps › Medication Distribution (three reinforce questions) → Progress report (encounter page, Patient Record, recurrent completion, WhatsApp copy) → Medical Diagnosis pane: "Anemia (Mild to Moderate) on dd/mm/yyyy - no treatment recorded".
- **Impact.** The clinical document read at the next facility misstates the treatment for every moderate-anemia encounter since the change. Both sites.
