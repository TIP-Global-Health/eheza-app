### B-213 — NCDA scorecard "Fill the Blanks": every past height/weight is graded against the child's age TODAY, so earlier months turn orange/red as the child grows — ✅ IMPLEMENTED (issue #2188, PR #2189, 2026-09-02) · was READY · CONFIRMED (orchestrator-read at anchor; LIVE on origin/main) · HIGH · tier 2 · **Rwanda only** (`ncda` flag = ihangane; 0 on vhw/uvl/tip-somalia) · R23 unit 2
- **Mechanism.** `Pages/WellChild/ProgressReport/View.elm:2617-2620` (`viewFillTheBlanksPane`): `maybeAgeInDays = Maybe.map (\birthDate -> diffDays birthDate currentDate) child.birthDate` — ONE age, computed once — is the `Days` argument for every historical measurement: `:2664` `zScoreLengthHeightForAge zscores ageInDays …` (heights from group sessions + Nutrition + WellChild), `:2707` and `:2725` `zScoreWeightForAge zscores ageInDays …` (same weight sources + CHW NCDA-questionnaire weights). Each measurement's own `date` is in scope in the same lambda but is used only to bucket the cell by month (`distributeByAgeInMonthsWithDate`). `cellValueByZscore` (`:2736-2744`) then paints z<-3 red / z<-2 orange / else green. Example: a median 6.4 kg at 3 months, viewed when the child is 20 months, is evaluated against the 20-month LMS row (−3SD ≈ 8.1 kg) → the month-3 cell shows red. The drift grows monthly with no data change; stunting row likewise. `zScoreForAge` (`ZScore/Utils.elm:88-95`) falls through by-day → by-month, so the wrong age is silently accepted rather than yielding `Nothing`.
- **Not affected (checked):** growth CHARTS use `diffDays birthDate dateMeasured` per point; MUAC/Edema rows have no age term. The server aggregated scorecard reads the stored per-node `field_zscore_age` (`hedley_ncda.module:568-607`) computed at measurement time — so device scorecard and backend scorecard DISAGREE on the same measurements. `Backend/NutritionEncounter/Utils.elm:626-635 calculateZScoreWeightForAge currentDate` is correct at its callers (current encounter only); the pane is the un-adapted copy.
- **Reachability.** `viewProgressReport` → `TabNCDAScoreboard` (offered whenever `ncdaEnabled features`) → `viewNCDAScorecard` (`:1595`) → `viewFillTheBlanksPane` (`:1667`). All five `WellChildProgressReportInitiator` variants (WellChild encounter, individual Nutrition, Child Scoreboard, group-nutrition child page, Patient Record) reach it.
- **Impact.** Every "Height to Age" / "Weight to Age" cell except the current month is graded against the wrong reference, on the clinical scorecard nurses and CHWs read. Deployed: `origin/main` carries the identical line (last touched 609d16982).
- **Fix shape (first guess):** compute `diffDays birthDate date` per measurement inside the three `filterMap` lambdas and drop `maybeAgeInDays`; or use each measurement's stored z-score where present, matching the server. Discriminating test: one old weight fed at two different `currentDate`s must give the same cell.
