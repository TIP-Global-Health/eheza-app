### B-404 — ⬖ SPLIT out of [[B-144]]: `minify`'s uglify error handler has no `isPublishing` guard, so `gulp publish` still cannot report a minification failure — READY · CONFIRMED (orchestrator read all three handlers) · LOW · tier 4 · R34 unit 4 · latent
- **Why it is its own entry.** B-144 fixed the Elm and SASS halves and filed this one as "Related PLAUSIBLE" inside an item that then closed. Per the R33 lesson, a surviving sibling recorded inside a closed item is invisible to the queue, so it is split out here.
- **Mechanism.** The `elm` and `styles` tasks now guard their swallowing handlers, and `minify` does not:
  ```js
  -- client/gulpfile.js:283-291
      return gulp.src("serve/**/*.*")
        .pipe($.if(["*.js", "!service-worker.js", "!workbox-*.js", "!app.js", "!bulkPhotos.js", "!nodes.js", "!photos.js", "!statistics.js"], uglify({
          mangle: false
        }))).on('error', function(err) {
          console.error(err);
        })
  ```
  The listener is attached to the gulp-if/uglify stream, consumes the `error` event and does not re-emit it on the stream the task returns. Because the error is consumed, async-done's domain never sees it; because through2 destroys the stream on `cb(err)` without emitting `end`, `gulp.dest` never finishes. The outcome is either a hang or a partial `dist` with exit 0 — in neither case does `publish` report failure.
- **Reachability.** `gulp publish` → `gulp.parallel("minify", "cname", "images")`. gulp-uglify 3.x is uglify-js, ES5-only. The files that actually reach it are the root-level `serve/*.js` minus the exclusion list: `Main.js` plus `src/js/{config,lifecycle,photoCache,sw,uuid}.js`.
- **Impact — latent, not firing today.** None of those five files contains `=>`, `const`, `let`, `async` or a template literal, and the deployed bytes prove uglify runs (`config.js` 3738→1269, `lifecycle.js` 358→110, `photoCache.js` 932→242, `sw.js` 9481→7136, `uuid.js` 7880→3678; the excluded files are byte-identical to source). The first ES6 line added to any of the five turns a publish into a hang or a silently short `dist`.
- **Fix shape (guess).** Give this handler the same `if (!isPublishing)` guard the `elm` and `styles` tasks already carry.
