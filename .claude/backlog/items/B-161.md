### B-161 — Well-child Completion report treats EVERY previously-administered medication as never administered (enrichment written to a by-value copy) — ✅ IMPLEMENTED 2026-08-11 (issue #2070, PR #2071, MERGED) · MED-HIGH · supervision-metric bias · R19 Unit 4
- `hedley_reports.module`: the well-child loop enriches a BY-VALUE copy — `foreach ($encounters_data as $index => $encounter_data)` with `$encounter_data['start_date_obj'] = $start_date_obj` (:4830) never written back to `$encounters_data[$index]` — while `previous_encounters_data = array_slice($encounters_data, 0, $index)` (:4834) slices the UN-enriched originals (elements carry only encounter/encounter_type/measurements_by_type, :4811-4815). `hedley_reports_well_child_add_medication_activities` then reads `$previous_encounter_data['start_date_obj']` (:6051) — **the only read of an enriched key from previous-encounter data module-wide** (self-verified: all other `previous_encounter_data[` reads are measurements_by_type/encounter/encounter_type, which ARE present) — gets NULL even when the `administered-today` record was FOUND, so `is_null` → medication expected whenever the child is in the age band, regardless of history.
